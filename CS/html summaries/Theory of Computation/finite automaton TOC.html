Finite Automata & Regular Languages

A comprehensive cheat sheet covering the Chomsky Hierarchy Type-3 languages, machine models, conversions, and properties.

1. Fundamentals

Symbol

Atomic unit (e.g., \( a, b, 0, 1 \)).

Alphabet (\(\Sigma\))

Finite, non-empty set of symbols. e.g., \(\Sigma = \{0, 1\}\).

String

Finite sequence of symbols. Length \(|w|\). Empty string is \(\epsilon\) or \(\lambda\).

Language (\(L\))

Set of strings over \(\Sigma\). \(L \subseteq \Sigma^*\).

Powers of Alphabet:
  • \(\Sigma^0 = \{\epsilon\}\)
  • \(\Sigma^1 = \Sigma\)
  • \(\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \Sigma^2 \dots\) (Kleene Star - set of all possible strings)
  • \(\Sigma^+ = \Sigma^1 \cup \Sigma^2 \dots\) (Positive Closure - excludes \(\epsilon\))

2. Regular Expressions (RE)

Algebraic description of a Regular Language.

Operators & Precedence

  1. Kleene Star (\(*\)): Zero or more repetitions. (Highest)
  2. Concatenation (\(\cdot\)): Sequence.
  3. Union (\(+\) or \(|\)): Choice. (Lowest)

Key Identities

  • \(\phi + R = R\)
  • \(\phi \cdot R = R \cdot \phi = \phi\)
  • \(\epsilon \cdot R = R \cdot \epsilon = R\)
  • \(\epsilon^* = \epsilon\) and \(\phi^* = \epsilon\)
  • \(R + R = R\) (Idempotent)
  • \((R^*)^* = R^*\)
  • \(R^+ = RR^* = R^*R\)
  • \(R^* = R^+ + \epsilon\)
⚡ Arden's Theorem If \(P\) and \(Q\) are REs over \(\Sigma\), and \(P\) does not contain \(\epsilon\), then the equation \(R = Q + RP\) has a unique solution \(R = QP^*\).

3. Deterministic Finite Automata (DFA)

A 5-tuple \((Q, \Sigma, \delta, q_0, F)\) where:

  • \(Q\): Finite set of states.
  • \(\Sigma\): Input alphabet.
  • \(\delta\): Transition function \(Q \times \Sigma \rightarrow Q\) (Deterministic: Exactly one move per symbol).
  • \(q_0\): Start state.
  • \(F\): Set of final states.

4. Non-Deterministic Finite Automata (NFA)

Similar to DFA but \(\delta: Q \times \Sigma \rightarrow 2^Q\) (Power set of Q).

  • Can have 0, 1, or multiple transitions for a symbol.
  • Can have \(\epsilon\)-moves (change state without reading input).
  • Accepted if at least one path leads to a final state.
⚡ Equivalence Every NFA can be converted to an equivalent DFA. \(L_{NFA} = L_{DFA}\). However, the DFA might have up to \(2^n\) states.

5. NFA to DFA Conversion

Uses the Subset Construction Algorithm.

  1. Start state of DFA = \(\epsilon\)-closure(Start state of NFA).
  2. For every new subset state created, find transitions for all alphabet symbols.
  3. Union of destinations becomes the new state.
  4. Final states of DFA = Any subset containing at least one final state from NFA.

7. Minimization of DFA

Goal: Partition states into sets of equivalent states.

Algorithm (Partition Refinement):
  1. Remove unreachable states.
  2. Divide states into two sets: Final (\(F\)) and Non-Final (\(Q-F\)).
  3. Iteratively refine partitions: Two states \(p, q\) are distinguishable if for some input \(a\), \(\delta(p,a)\) and \(\delta(q,a)\) land in different partitions.
  4. Stop when no further splits are possible.

Type-3 Grammars in Chomsky Hierarchy.

\(A \rightarrow xB\) or \(A \rightarrow x\) \(A \rightarrow Bx\) or \(A \rightarrow x\)

Note: A grammar cannot mix Left Linear and Right Linear productions.

9. Pumping Lemma

Used to prove that a language is NOT Regular (Proof by Contradiction).

The Theorem:

If \(L\) is regular, there exists a constant \(P\) (pumping length) such that any string \(w \in L\) with \(|w| \ge P\) can be split into \(w = xyz\) satisfying:

  1. \(|xy| \le P\)
  2. \(|y| > 0\) (y cannot be empty)
  3. For all \(i \ge 0\), \(xy^iz \in L\)
Common Non-Regular Languages
  • \(L = \{ a^n b^n \mid n \ge 0 \}\) (Requires memory/counting)
  • \(L = \{ w w^R \mid w \in \{a,b\}^* \}\) (Palindrome with center marker)
  • \(L = \{ a^p \mid p \text{ is prime} \}\)
  • \(L = \{ a^{n^2} \mid n \ge 0 \}\)
  • Balanced Parentheses

11. Decidability for Regular Languages

The following problems are Decidable for Regular Languages (i.e., an algorithm exists):

  • Membership: Is \(w \in L\)? (Run w on DFA)
  • Emptiness: Is \(L = \phi\)? (Is any final state reachable?)
  • Finiteness: Is \(L\) finite? (Check for loops on path to final state)
  • Equivalence: Is \(L_1 = L_2\)? (Check if \((L_1 \cap \bar{L_2}) \cup (\bar{L_1} \cap L_2) = \phi\))
  • Subset: Is \(L_1 \subseteq L_2\)? (Check if \(L_1 \cap \bar{L_2} = \phi\))
