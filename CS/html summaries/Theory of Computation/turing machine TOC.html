Theory of Computation: Turing Machines

From Finite Automata to Recursively Enumerable Languages (REL). A guide to decidability, halting, and closure properties.

1. Machine Comparison

Evolution of computational power based on memory capabilities.

Finite Automata (FA)

Memory: None (Finite Control)

Tape: Read-only, Move Right only.

Power: Least powerful.

Languages: Regular.

Push Down Automata (PDA)

Memory: Finite Control + 1 Stack.

Tape: Read-only.

Power: Context Free.

Key: $PDA \cong FA + 1 \text{ Stack}$.

Turing Machine (TM)

Memory: Finite Control + Infinite Tape.

Tape: Read/Write, Bidirectional (Left/Right).

Power: Most powerful (Computer).

Key: $TM \cong FA + \text{R/W Tape} + \infty \text{ Memory}$.

2. Formal Definition

A Turing Machine is a 7-tuple: $$TM = (Q, \Sigma, \Gamma, \delta, q_0, B, F)$$

  • \(Q\): Finite set of states.
  • \(\Sigma\): Input alphabet (subset of \(\Gamma\)).
  • \(\Gamma\): Tape alphabet (contains input symbols + Blank \(B\) + auxiliaries).
  • \(\delta\): Transition function.
  • \(q_0\): Start state.
  • \(B\): Blank symbol (initially fills infinite tape).
  • \(F\): Set of Final/Accepting states.

Transition Function Logic

The core logic of a TM is defined as: \(\delta: Q \times \Gamma \rightarrow Q \times \Gamma \times \{L, R\}\)

Meaning: Given current state \(q\) and reading symbol \(X\), go to state \(p\), overwrite \(X\) with \(Y\), and move Head Left or Right.

3. Construction & Variations

Deterministic TM (Standard)

For every state and input symbol, there is exactly one transition.

Used for Recursively Enumerable Languages (REL).

Halting TM (HTM)

A TM that always halts, regardless of input (never enters an infinite loop).

Used for Recursive Languages (Decidable).

Example: Logic for \(L = \{a^n b^n \mid n \geq 1\}\)

Strategy: Zig-zag approach. Mark 'a' with 'X', move right to find corresponding 'b', mark with 'Y', return left.

4. Language Hierarchy

The containment relationship of formal languages.

Key Distinctions

  • Regular: Can be done without memory (e.g., parity check).
  • DCFL/CFL: Needs 1 stack (e.g., \(a^n b^n\), Palindromes).
  • CSL (LBA): Needs Bounded Tape (e.g., \(a^n b^n c^n\), \(ww\)).
  • Recursive: Logic exists for Valid AND Invalid strings (Total Turing Machine).
  • REL: Logic exists for Valid strings only (Partial Turing Machine).

5. Decidability & Computability

Understanding the limits of computation. "Decidable" roughly translates to "Solvable by an algorithm that always finishes".

Language Class Alternative Name Machine Type Behavior on Input \(w\)
Recursive Decidable Halting TM (HTM) \(w \in L\): Halt & Accept
\(w \notin L\): Halt & Reject
REL Semi-Decidable / Recognizable Standard TM \(w \in L\): Halt & Accept
\(w \notin L\): Halt & Reject OR Loop Forever

Logic of Complements

Theorem 1: If \(L\) is Recursive, then \(\bar{L}\) is Recursive. (We can flip Accept/Reject states).

Theorem 2: If \(L\) is REL and \(\bar{L}\) is REL, then \(L\) is Recursive.

Theorem 3: If \(L\) is REL but NOT Recursive, then \(\bar{L}\) is NOT REL.

6. Closure Properties

Which operations keep a language within its class?

Operation Recursive (Decidable) REL (Semi-Decidable)
Union (\(\cup\)) Yes Yes
Intersection (\(\cap\)) Yes Yes
Concatenation (\(\cdot\)) Yes Yes
Kleene Star (\(*\)) Yes Yes
Complement (\(\bar{L}\)) Yes NO
Difference (\(-\)) Yes NO
Subset (\(\subseteq\)) NO NO
Why is Recursive closed under Complement?

Because Recursive languages have an HTM. An HTM always halts. If we swap the "Accept" and "Reject" states, we get a machine that accepts exactly when the original rejected. Thus, \(\bar{L}\) is also Recursive.

Why is REL NOT closed under Complement?

For an REL, the TM might loop on invalid strings. We cannot simply "swap" states because we never reach a "Reject" state in an infinite loop. We don't know if it's still thinking or if it will never finish.

7. Quick Summary Definitions

Recursive Language

  • Is Turing Decidable.
  • Has an Algorithm.
  • Has a Halting Program.
  • Logic exists for Valid AND Invalid.

REL (Recursively Enumerable)

  • Is Turing Recognizable.
  • Is Semi-Decidable.
  • Logic exists for Valid strings.
  • Logic may or may not exist for Invalid strings.

Undecidable

  • Can be REL but not Recursive (Halting Problem).
  • Can be Not REL.
  • No algorithm exists to solve these for all inputs.

LBA (Linear Bounded Automata)

  • Tape is finite (bounded by input length).
  • Accepts Context Sensitive Languages (CSL).
  • More powerful than PDA, less than TM.
