Flow Control & Error Control

Comprehensive notes on Data Link Layer flow control mechanisms, delays, and ARQ protocols.

1. Network Performance Primitives

Four Types of Delay

Total Time = Transmission + Propagation + Queuing + Processing

graph LR A[Packet Created] --> B(Processing Delay) B --> C(Queuing Delay) C --> D(Transmission Delay) D --> E[Propagation Delay] E --> F[Destination] style D fill:#dbeafe,stroke:#1e40af style E fill:#dbeafe,stroke:#1e40af

Td Transmission Delay

Time to push packet bits onto the link.

$$T_d = \frac{L}{B}$$
  • \(L\): Packet Length (bits)
  • \(B\): Bandwidth (bits/sec)

Pd Propagation Delay

Time for one bit to travel from sender to receiver.

$$P_d = \frac{d}{v}$$
  • \(d\): Distance (meters)
  • \(v\): Velocity (m/s)
Key Insight: Efficiency Ratio (a)
The factor \(a\) defines how many packets can fit on the link during one propagation time. $$ a = \frac{P_d}{T_d} = \frac{\text{Propagation Time}}{\text{Transmission Time}} $$

2. Stop & Wait Protocol

The simplest flow control. Sender sends one frame, stops, and waits for Acknowledgement (ACK).

sequenceDiagram participant Sender participant Receiver Note over Sender: Td (Transmission) Sender->>Receiver: Frame 0 Note over Receiver: Processing Receiver-->>Sender: ACK 1 Note over Sender: RTT (Round Trip Time) Sender->>Receiver: Frame 1

Stop & Wait ARQ (Automatic Repeat Request)

Adds Error Control to Stop & Wait using Timeouts and Sequence Numbers.

Problem: Lost Data
Sender waits for ACK. If timer expires (Time Out), sender retransmits the frame.
Problem: Lost ACK
Sender times out and retransmits. Receiver detects duplicate using Sequence No (0 or 1) and discards it, resending ACK.
Problem: Delayed ACK
If ACK arrives after timeout, sender has already retransmitted. Receiver handles duplicate. Sender ignores late duplicate ACK.

Performance Analysis

Efficiency (\(\eta\)) = \(\frac{\text{Useful Time}}{\text{Total Cycle Time}} = \frac{T_d}{T_d + 2P_d} = \frac{1}{1 + 2a}\)

Throughput

$$ \text{Throughput} = \eta \times \text{Bandwidth} $$

Note: Stop & Wait is very inefficient for links with high propagation delay (e.g., Satellites) because the link sits idle most of the time.

3. Concept of Pipelining (Sliding Window)

To improve efficiency, we allow the sender to have multiple unacknowledged packets "in flight".

Window Size (N): The number of packets sent before waiting for an ACK.
For 100% Utilization: $$ N \ge 1 + 2a $$

4. Go-Back-N (GBN) ARQ

Uses Cumulative ACKs. If Frame \(k\) is lost, all frames \(>k\) are discarded by receiver. Sender retransmits everything from \(k\).

Protocol Characteristics

  • Sender Window (\(W_s\)): Size \(N\) (where \(N > 1\)).
  • Receiver Window (\(W_r\)): Always 1. Receiver expects packets strictly in order.
  • Acknowledgement: Cumulative (ACK \(n\) means "I expect \(n\), have received up to \(n-1\)").
sequenceDiagram participant S as Sender (Ws=3) participant R as Receiver (Wr=1) S->>R: Pkt 0 S->>R: Pkt 1 (LOST) X S->>R: Pkt 2 R-->>S: ACK 1 (Exp 1) Note right of R: Discard Pkt 2 (Out of order) Note left of S: Timeout for Pkt 1 S->>R: Retransmit Pkt 1 S->>R: Retransmit Pkt 2

Sequence Number Requirements

To avoid ambiguity between new frames and retransmissions:

Available Sequence Numbers \(\ge W_s + W_r\)
Since \(W_r = 1\), \(\text{Seq} \ge N + 1\)

If \(k\) bits are used for sequence numbers: \(W_s \le 2^k - 1\).

Efficiency

$$ \eta = \frac{N}{1+2a} $$

5. Selective Repeat (SR) ARQ

Receiver buffers out-of-order packets. Sender only retransmits the specific lost packet. Uses Independent ACKs (or Negative ACKs).

Protocol Characteristics

  • Sender Window (\(W_s\)): Size \(N\).
  • Receiver Window (\(W_r\)): Size \(N\) (Same as sender).
  • Logic: Searching and Sorting required at receiver to reorder buffered packets.
sequenceDiagram participant S as Sender (Ws=3) participant R as Receiver (Wr=3) S->>R: Pkt 0 S->>R: Pkt 1 (LOST) X S->>R: Pkt 2 R-->>S: ACK 0 Note right of R: Buffer Pkt 2, Send NAK 1 S->>R: Retransmit Pkt 1 Note right of R: Deliver 0, 1, 2

Sequence Number Requirements

To ensure no overlap between windows:

Available Sequence Numbers \(\ge W_s + W_r\)
Since \(W_s = W_r = N\), \(\text{Seq} \ge 2N\)

If \(k\) bits are used for sequence numbers: \(W_s \le 2^{k-1}\).
