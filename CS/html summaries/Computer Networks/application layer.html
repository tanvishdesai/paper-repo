Application Layer Overview

The Application Layer interacts directly with the software application (Browser, Email Client). It relies on the Transport Layer (TCP/UDP) to move data.

Client-Server Model

Most protocols follow this architecture: Client requests service, Server provides it. (e.g., HTTP, FTP, SMTP).

In-Band vs Out-of-Band

In-Band: Control info & data share the same connection (HTTP, SMTP).
Out-of-Band: Separate connections for control & data (FTP).

1. SMTP (Simple Mail Transfer Protocol)

Core Specs

  • Port: 25
  • Transport: TCP
  • Type: Push Protocol
  • Nature: Stateless

Functionality

  • Used twice: Sender to Server, and Server to Server.
  • Text-based: Only handles 7-bit ASCII.
  • MIME: Required for non-text (images/video) to convert to ASCII.
GATE Note: SMTP is purely for sending/pushing mail. It cannot be used by the receiver to download mail from the server.

2. Mail Access Protocols (Pull)

Since SMTP pushes to the server, the receiver needs a protocol to "pull" the email to their device.

Feature POP3 (Post Office Protocol v3) IMAP4 (Internet Message Access Protocol)
Port 110 (TCP) 143 (TCP)
Primary Action Download & Delete (default) or Keep Sync / Manage on Server
Multiple Devices Poor support (Inbox fragmentation) Excellent support (Fully synced)
Organization Cannot organize on server Create/Rename folders on server

State Stateful (Update phase) Stateful

Base64 Encoding

SMTP was designed for text (7-bit ASCII). To send binary data (images, audio) via SMTP, we use MIME (Multipurpose Internet Mail Extension), which often uses Base64 encoding.

The Algorithm

$$ 3 \text{ bytes of Input} \times 8 \text{ bits} = 24 \text{ bits} $$

$$ 24 \text{ bits} \div 6 \text{ bits} = 4 \text{ Base64 Characters} $$

Result: 33% overhead increase.

Example: Encoding "And"

'A' 010000 Q
'n' 010110 W
'd' 111001 5
(pad) 100100 K

Result: And → QW5K

Base64 Index Table
  • 0-25: A-Z
  • 26-51: a-z
  • 52-61: 0-9
  • 62: +
  • 63: /

DNS (Domain Name System)

Maps human-readable Domain Names (e.g., www.google.com) to IP Addresses (e.g., 74.125.239.35).

Transport Protocol

Standard: UDP Port 53

Exception: Uses TCP Port 53 if response size > 512 bytes (Zone Transfers).

Hierarchy

Root (.) → TLD (.com, .edu) → Authoritative (example.com).

There are 13 logical Root Name Servers worldwide.

Query Resolution Methods

Iterative Query

The "I'll give you a referral" approach. The Local DNS server does the work.

Recursive Query

The "Pass the buck" approach. Burden is on the Root/TLD servers.

FTP (File Transfer Protocol)

Standard protocol for transferring files between computers. Stateful and Out-of-Band.

Crucial: FTP uses TWO parallel TCP connections.

Control Connection

  • Port: 21
  • Type: Persistent
  • Stays open during the entire session.
  • Used for commands (USER, PASS, CWD).

Data Connection

  • Port: 20
  • Type: Non-Persistent
  • Opened and closed for each file transfer.
  • Used for actual file data.

Transmission Modes

  • Stream Mode: Default. Continuous stream of bytes.
  • Block Mode: Data divided into blocks with 3-byte headers.
  • Compressed Mode: Data compressed (RLE) for bandwidth efficiency.

HTTP (HyperText Transfer Protocol)

The foundation of the World Wide Web. Client-Server, Stateless, In-Band.

  • Port: 80
  • Transport: TCP

Connection Types

HTTP 1.0: Non-Persistent

One TCP connection per object.

1. Open TCP
2. Send Request
3. Receive Response
4. Close TCP

High overhead.

Formula: For a page with 1 text + N images:
$$ \text{Total Connections} = N + 1 $$

HTTP 1.1: Persistent

Multiple objects over a single TCP connection.

1. Open TCP
2. Request Obj 1, 2, 3...
3. Receive Obj 1, 2, 3...
4. Close TCP (on timeout)

Efficient.

Common HTTP Methods
  • GET: Request a document.
  • HEAD: Request headers only (debug/check).
  • POST: Send data to server (forms).
  • PUT: Upload/Replace resource.
  • DELETE: Remove resource.

GATE Short Tricks

  • Real-time/Multimedia: Uses UDP.
  • Email Chain: Sender → SMTP → SMTP → POP3/IMAP → Receiver.
  • Stateless Protocols: HTTP, SMTP, DNS.
  • Stateful Protocols: FTP, POP3, IMAP, Telnet.
