1. Graph Traversal

Depth First Search (DFS)

Explores as deep as possible along each branch before backtracking. Uses a Stack (LIFO).

  • Time Complexity: \(O(V + E)\) (Adj List), \(O(V^2)\) (Adj Matrix)
  • Key Metric: Discovery time \(d[u]\) and Finish time \(f[u]\).

Breadth First Search (BFS)

Explores all neighbor nodes at the present depth before moving to nodes at the next depth level. Uses a Queue (FIFO).

  • Time Complexity: \(O(V + E)\)
  • Application: Shortest Path in unweighted graphs.

Edge Classification (Directed Graphs)

When running DFS on a directed graph, edges fall into four categories based on the relationship between nodes \(u\) and \(v\):

Edge Type Visual Condition Description
Tree Edge \(u \rightarrow v\) Normal visit Edge in the DFS forest (Child).
Back Edge \(u \dashrightarrow v\) \(v\) is ancestor of \(u\) Connects to an ancestor. Implies a Cycle. Interval \([d[u], f[u]] \subset [d[v], f[v]]\).
Forward Edge \(u \rightarrow v\) \(v\) is descendant Connects to a non-child descendant. Interval \([d[v], f[v]] \subset [d[u], f[u]]\).
Cross Edge \(u \rightarrow v\) No relation Connects "sideways". Intervals are disjoint.

2. Bellman-Ford Algorithm

Single Source Shortest Path (SSSP) algorithm that handles negative edge weights (unlike Dijkstra).

Algorithm Negative Cycles
Time: O(VE)

Core Logic: Relaxation

We relax all edges \(|V|-1\) times. If we can still relax an edge on the \(|V|\)-th iteration, a negative weight cycle exists.

Relaxation Equation:
If \( d[u] + w(u, v) < d[v] \)
Then \( d[v] = d[u] + w(u, v) \)
Pseudocode Step-by-Step 
Bellman-Ford(G, w, s):
  Initialize-Single-Source(G, s)
  
  // Relax all edges |V| - 1 times
  for i = 1 to |V| - 1:
      for each edge (u, v) in E:
          Relax(u, v, w)

  // Check for negative weight cycles
  for each edge (u, v) in E:
      if d[v] > d[u] + w(u, v):
          return FALSE (Negative Cycle Detected)
          
  return TRUE

3. Advanced Graph Concepts

Topological Sort

Linear ordering of vertices in a Directed Acyclic Graph (DAG) such that for every edge \(u \to v\), \(u\) comes before \(v\).

  • Method: Run DFS. Upon finishing a node (turning it black/dead), push it to a stack (or list front).
  • Formula: Sort by decreasing Finishing Time \(f[u]\).

Connected Components

  • SCC (Strongly Connected): Maximal set of vertices in a directed graph where every pair is mutually reachable (\(u \leftrightarrow v\)).
  • SCC Property: The graph of SCCs forms a DAG.

Articulation Points & Bridges

Critical vulnerabilities in network structures.

Articulation Point (Cut Vertex) Biconnected Component
A vertex which, if removed (along with incident edges), increases the number of connected components. A maximal subgraph that contains no articulation points (cannot be disconnected by removing a single vertex).
Detected via DFS: Root with >1 child OR non-root \(u\) with child \(v\) having no back-edge to ancestor of \(u\). Graph edges partitioned into biconnected components.

4. Sorting Taxonomy

In-Place vs Out-of-Place

In-Place: Uses constant extra space \(O(1)\) (e.g., Bubble, Insertion, Heap).

Out-of-Place: Requires extra memory (e.g., Merge Sort \(O(n)\)).

Stable vs Unstable

Stable: Preserves relative order of equal elements.

Input: [2a, 2b, 1]
Stable: [1, 2a, 2b]
Unstable: [1, 2b, 2a]

Inversions

Pair \((i, j)\) is an inversion if \(i < j\) and \(A[i] > A[j]\).

Measure of "unsortedness". Max inversions = \(n(n-1)/2\).

5. Sorting Algorithms

Bubble Sort O(n²)

Repeatedly swaps adjacent elements if they are in wrong order. "Bubbles" largest element to the end.

  • Optimization: Use a `flag`. If no swaps occur in a pass, break (Best Case \(O(n)\)).
  • Analysis: Comparisons \(\approx n^2/2\), Swaps \(\approx n^2/2\) (worst).
Selection Sort O(n²)

Finds the minimum element in the unsorted part and puts it at the beginning.

  • Key Feature: Minimizes swaps! Makes exactly \(O(n)\) swaps in all cases. Good when writing to memory is expensive.
  • Stability: Generally Unstable.
Insertion Sort O(n²)

Builds sorted array one item at a time. Takes element, shifts larger elements right, inserts into correct gap.

  • Best Case: \(O(n)\) (Already sorted).
  • Use Case: Very efficient for small datasets or nearly sorted data (number of inversions \(d\) is small -> \(O(n+d)\)).
  • Online: Can sort data as it is received.
Radix Sort O(d(n+b))

Non-comparison based. Sorts digit by digit from least significant to most significant (LSD).

  • \(d\): Number of digits (bits).
  • \(b\): Base (e.g., 10 or 2).
  • Uses a stable subroutine (like Counting Sort) for each digit.

💡 Professor's Notes

  • Cycle Detection: Use DFS. Back-edge = Cycle.
  • Shortest Path:
    • Unweighted? Use BFS.
    • Positive weights? Use Dijkstra.
    • Negative weights? Use Bellman-Ford.
    • DAG? Use Topological Sort + Relaxation \(O(V+E)\).
  • Minimum Swaps to Sort: Selection Sort performs minimum swaps \(O(n)\). Sorting an array with minimum swaps generally involves following cycles in permutation decomposition.
