1. The Elements of Dynamic Programming

Dynamic Programming (DP) is an optimization technique used to solve problems by breaking them down into simpler subproblems. Unlike Divide & Conquer, DP subproblems overlap.

1. Optimal Substructure

A problem has optimal substructure if an optimal solution can be constructed from optimal solutions of its subproblems. (Principle of Optimality).

2. Overlapping Subproblems

The problem can be broken down into subproblems which are reused several times. DP stores these results to avoid re-computation.

DP Implementation Strategies

Feature Memoization (Top-Down) Tabulation (Bottom-Up)
Approach Recursive. Solves subproblems only when needed. Iterative. Solves all subproblems starting from the smallest.
Storage Caches result in table after computing. Fills table based on previous entries.
Pros/Cons Good if not all subproblems need solving. High recursion overhead. No recursion overhead. Efficient if all subproblems must be visited.

3. Multistage Graphs

Finding the shortest path from source \(s\) to sink \(t\) in a graph partitioned into \(k\) stages where edges only go from stage \(i\) to \(i+1\).

$$Cost(i, j) = \min_{k \in V_{i+1}} \{ c(j, k) + Cost(i+1, k) \}$$

Backward Approach

  • Start from the destination (sink).
  • Compute cost to reach sink from previous stage vertices.
  • Work backwards to source.
  • Time Complexity: \(O(n^2)\) or \(O(|V| + |E|)\)

4. Traveling Salesperson Problem (TSP)

Find the minimum cost tour starting at city 1, visiting every other city exactly once, and returning to 1.

Algorithm: Held-Karp (Dynamic Programming)
$$g(i, S) = \min_{k \in S} \{ c(i, k) + g(k, S - \{k\}) \}$$
  • \(g(i, S)\): Cost of path starting at vertex \(i\), visiting all vertices in set \(S\), and terminating at vertex 1.
  • Base Case: \(g(i, \emptyset) = c(i, 1)\)
Brute Force
\(O(n!)\)
DP (Held-Karp)
\(O(n^2 2^n)\)
Exponential Space & Time

5. All-Pairs Shortest Paths (Floyd-Warshall)

Computes shortest paths between every pair of vertices. Works with negative edges (but no negative cycles).

The Recurrence (Vertex \(k\) as intermediate)

Let \(A^k[i, j]\) be the shortest path from \(i\) to \(j\) using only vertices \(\{1, ..., k\}\) as intermediates.

$$A^k[i, j] = \min ( \underbrace{A^{k-1}[i, j]}_{\text{Don't use } k}, \underbrace{A^{k-1}[i, k] + A^{k-1}[k, j]}_{\text{Use } k} )$$
for k from 1 to n:
  for i from 1 to n:
    for j from 1 to n:
      A[i,j] = min(A[i,j], A[i,k] + A[k,j])
Time: \(O(n^3)\) Space: \(O(n^2)\) Used for Transitive Closure

6. 0/1 Knapsack Problem

Given items with weights \(w_i\) and profits \(p_i\), maximize total profit such that total weight \(\le M\). Items cannot be broken (0 or 1).

$$V[i, w] = \begin{cases} V[i-1, w] & \text{if } w_i > w \\ \max(V[i-1, w], \quad V[i-1, w-w_i] + p_i) & \text{if } w_i \le w \end{cases}$$

Logic Table Construction

i \ w01...M
000...0
10.........
n0......Max

Complexity

  • Time: \(O(n \times M)\) (Pseudo-polynomial)
  • Space: \(O(n \times M)\)

Greedy method fails for 0/1 Knapsack (works only for Fractional Knapsack).

7. Longest Common Subsequence (LCS)

Find the longest subsequence present in both strings \(X\) (len \(n\)) and \(Y\) (len \(m\)). Order matters, continuity does not.

$$L[i, j] = \begin{cases} 0 & \text{if } i=0 \text{ or } j=0 \\ 1 + L[i-1, j-1] & \text{if } X[i] == Y[j] \\ \max(L[i-1, j], L[i, j-1]) & \text{if } X[i] \neq Y[j] \end{cases}$$

8. Matrix Chain Multiplication (MCM)

Given a sequence of matrices, find the most efficient way to parenthesize them to minimize the number of scalar multiplications.

Matrix \(A_i\) has dimensions \(p_{i-1} \times p_i\).

$$m[i, j] = \begin{cases} 0 & \text{if } i=j \\ \min_{i \le k < j} \{ m[i, k] + m[k+1, j] + p_{i-1}p_kp_j \} & \text{if } i < j \end{cases}$$

Filling the Table

The table is filled diagonally based on chain length (\(L\)).

  • L=1: (A1), (A2)... Cost 0
  • L=2: (A1A2), (A2A3)...
  • L=3: (A1A2A3)...
  • ...
  • L=n: Final Answer
Complexity
\(O(n^3)\)

Number of parenthesizations follows Catalan Numbers \(\Omega(4^n/n^{3/2})\).

9. Sum of Subsets (Subset Sum)

Given a set of integers and a target sum \(M\), determine if any subset sums up to \(M\).

$$Subset(i, j) = Subset(i-1, j) \lor Subset(i-1, j - A[i])$$

Can we get sum \(j\) using first \(i\) items? Either we don't include item \(i\) (look up), or we include item \(i\) (look up and left by value \(A[i]\)).

NP-Complete Problem DP Solution: \(O(n \times M)\)

10. Bellman-Ford Algorithm

Single Source Shortest Path algorithm that handles negative edge weights. It can also detect negative weight cycles.

1. Initialize dist[s] = 0, others = ∞
2. Repeat (V-1) times:
   For each edge (u, v) with weight w:
     if dist[u] + w < dist[v]:
       dist[v] = dist[u] + w (Relaxation)
3. Check for negative cycles (Run relaxation once more)

vs Dijkstra

Dijkstra (Greedy) fails with negative edges. Bellman-Ford (DP-ish) works but is slower.

Complexity

\(O(V \times E)\)
