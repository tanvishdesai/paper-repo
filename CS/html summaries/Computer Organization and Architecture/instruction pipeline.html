Instruction Pipelining Cheat Sheet

A comprehensive guide to improving system performance by overlapping instruction execution. Includes RISC architecture, Performance Evaluation, and Hazard Handling.

1. The Concept

Pipelining is a technique where multiple instructions are overlapped in execution. It is analogous to an assembly line.

Rather than finishing one instruction completely before starting the next (Sequential), we break execution into Stages (Segments).


  • Input: New instruction enters at one end.
  • Throughput: Rate at which instructions exit the pipeline.
  • Clock: All stages operate under a common synchronized clock.

2. Performance Evaluation

Cycle Time (\(t_p\))

The clock cycle time is determined by the slowest stage in the pipeline.

Uniform Delay:

$$ t_p = \text{Stage Delay} + \text{Buffer Delay} $$

Non-Uniform Delay:

$$ t_p = \max(\text{Stage Delays}) + \text{Buffer Delay} $$

Execution Time (ET)

Time to execute \(n\) instructions with \(k\) stages.

Non-Pipelined

$$ ET_{non-pipe} = n \times t_n $$ Where \(t_n\) is time for 1 instruction (sum of all stages).

Pipelined

$$ ET_{pipe} = [k + (n-1)] \times t_p $$ First instruction takes \(k\) cycles, remaining \(n-1\) take 1 cycle each.

Speedup (S) & CPI

$$ S = \frac{ET_{non-pipe}}{ET_{pipe}} = \frac{n \times t_n}{[k + (n-1)] \times t_p} $$
  • Ideal Speedup: When \(n\) is very large (infinite), \(S_{ideal} = \frac{t_n}{t_p}\).
  • Perfectly Balanced Stages: \(t_n = k \times t_p\), so Max Speedup \(= k\).
  • Ideal CPI: Cycles Per Instruction in a pipeline = 1.
  • Actual CPI: \(1 + \text{Stalls per Instruction}\).

4. Pipeline Hazards

Hazards prevent the next instruction from executing during its designated clock cycle. They cause Stalls (Bubbles).

Structural Hazard

Cause: Hardware Resource Conflict. Two instructions try to use the same resource at the same time.

Example: IF stage and MA stage both trying to access Main Memory in the same cycle.

Solution:

  • Resource Replication: Separate Instruction Cache (I-Cache) and Data Cache (D-Cache).
  • Renaming: Memory interleaving.

Control Hazard

Cause: Branch Instructions. The pipeline decision depends on the result of a previous instruction (Jump/Branch), changing the PC (Program Counter).

Effect: Instructions fetched after the branch might need to be flushed.

Solutions:

  • Prediction: Static (Always Taken/Not Taken) or Dynamic (Branch Prediction Buffer).
  • Delayed Branch: Compiler rearranges safe instructions into the "delay slot" after the branch.

5. Data Hazards

Occur when instructions depend on the results of previous instructions that haven't finished yet.

Types of Dependencies

Type Name Description Hazard?
RAW Read After Write J reads before I writes (True Dependency). J gets old data. YES
WAR Write After Read J writes before I reads (Anti-Dependency). I gets new data (wrong). Rare*
WAW Write After Write J writes before I writes (Output Dependency). Final value is wrong. Rare*
*WAR and WAW usually solved by Register Renaming and occur mostly in Out-of-Order execution processors.

Solution: Operand Forwarding (Bypassing)

Instead of waiting for the value to be written to the Register File (WB stage), hardware routes the data directly from the ALU output (EX stage) or Memory output (MA stage) to the input of the next instruction.

Advanced Concept: Split-Phase Register Access

To reduce stalls further, the Register File can be designed to write in the first half of the clock cycle and read in the second half.

This allows WB (Write Back) of Instruction 1 and ID (Instruction Decode/Read) of Instruction 2 to happen in the same cycle without a hazard.

6. Formula Cheat Sheet

Execution Time (Pipeline) \( ET_{pipe} = (k + n - 1) \times t_p \)
Cycle Time (\(t_p\)) \( \max(\text{Stage Delays}) + \text{Buffer Delay} \)
Ideal Speedup \( S = k \) (Number of stages)
Throughput \( \frac{1}{t_p} \) (Instructions per second)
Efficiency \( \frac{S}{k} \)
CPI with Stalls \( 1 + \text{Average Stalls per Instruction} \)
Branch Penalty If target known at stage \(k\): Penalty = \(k - 1\) cycles
