1. Introduction to COA

Computer Architecture (CA)

"What the programmer sees"

  • Attributes visible to the programmer.
  • Instruction Set Architecture (ISA).
  • Data types, Addressing modes.
  • Example: Intel x86 family share the same architecture.

Computer Organization (CO)

"How features are implemented"

  • Operational units and interconnections.
  • Hardware implementation details transparent to the programmer.
  • Memory technology, Control signals, Interfaces.
  • Example: Intel 80286 vs 80386 have different organization but same architecture.

Stored Program Concept: Memory holds both instructions and data. The CPU fetches instructions one by one.

2. Computer Components

Crucial

PC (Program Counter)

Holds the address of the next instruction to be fetched/executed.

Memory Access

MAR (Memory Address Register)

Holds the memory address for the current Read or Write operation. Connected to Address Bus.

Data Buffer

MBR / MDR (Memory Buffer Register)

Holds the data/instruction being transferred to/from memory. Connected to Data Bus.

Execution

IR (Instruction Register)

Holds the instruction currently being executed. (Format is defined here).

ALU

AC (Accumulator)

Holds temporary ALU results or the first operand of an operation.

System

PSW (Program Status Word)

Flag register: Carry, Parity, Sign, Zero, Overflow.

3. System Bus Architecture

The System Bus connects CPU, Memory, and I/O. It consists of three lines:

Bus Type Direction Function
Address Bus Unidirectional (CPU → Memory/IO) Carries the address of the memory location to access. Width determines Max Memory Capacity.
Data Bus Bidirectional Carries actual instructions and data. Width determines Word Length / Performance.
Control Bus Mixed (Collectively Bidirectional) Carries signals like READ ($\overline{RD}$), WRITE ($\overline{WR}$), Interrupts.

Pin Multiplexing (e.g., 8085 AD0-AD7)

Address and Data lines are often combined to save hardware pins (Time Multiplexed).

  • ALE (Address Latch Enable) = 1: Lines carry Address.
  • ALE = 0: Lines carry Data.

4. Memory Concepts

The Golden Formula

$$ Capacity = 2^n \times m $$
  • n: Number of Address Lines.
  • m: Number of Data Lines (Cell Size).
  • Total Cells: $$2^n$$

Powers of 2 Reference

$2^{10} = 1K$ (Kilo)
$2^{20} = 1M$ (Mega)
$2^{30} = 1G$ (Giga)
$2^{40} = 1T$ (Tera)

Addressing Modes

Byte Addressable (Default)

1 Cell = 8 bits

Every 8 bits (1 Byte) has a unique address. Standard in most modern systems.

Word Addressable

1 Cell = Word Size

Address points to a "Word" (e.g., 16-bit, 32-bit). If Word = 32-bit, address increment skips 4 bytes.

Phase 1: Fetch Cycle

Objective: Bring instruction from Memory to CPU (IR).

  1. PC → MAR
  2. Memory[MAR] → MBR
  3. MBR → IR
  4. PC + 1 → PC

Phase 3: Interrupt Cycle

Occurs after Execute cycle completed, before next Fetch.

  • Used to handle external requests (I/O).
  • Context Switch: Current PC is pushed to Stack (Return Address).
  • PC is loaded with address of ISR (Interrupt Service Routine).

6. Solved Problems

Q1: Calculate Address Lines for 4GB RAM (Word Addressable) ▼

Given: Memory = 4GB, Word Size = 16-bit (2 Bytes).

Solution:

Memory Size = 4GB = $2^{32}$ Bytes
Word Size = 2 Bytes
Number of Words = Total Capacity / Word Size
$$ \frac{4GB}{2B} = 2G \text{ Words} $$
$$ 2G = 2^1 \times 2^{30} = 2^{31} $$
Address Lines = 31 bits
Q2: PC Value after Instruction Fetch (Byte vs Word) ▼

Scenario: PC starts at 1000. Instruction size is 32-bit.

Case A: Byte Addressable

1 Word = 4 Bytes.

PC increments by number of bytes.

Next PC = $1000 + 4 = 1004$

Case B: Word Addressable

1 Cell = 1 Word.

PC increments by 1 (logical index).

Next PC = $1000 + 1 = 1001$

Q3: Return Address on Stack during Interrupt ▼

Scenario: Instruction $I_5$ is executing (Size 2 words). $I_5$ is stored at address 1008 (Decimal). Memory is Word Addressable.

1. Fetch $I_5$ starts at 1008.

2. During Fetch, PC updates to next instruction address.

3. Next Instruction ($I_6$) is at $1008 + 2 = 1010$.

4. Interrupt is serviced after execution of $I_5$.

5. Value pushed to Stack (Return Address) = 1010.
