Comprehensive Cheat Sheet based on Lecture Notes by Satish Yadav Sir

Covering Propositional Logic, Inference Rules, First Order Logic, and Nested Quantifiers.

1. Propositional Logic Basics

Definitions

  • Proposition: A declarative statement that is either True (T) or False (F), but not both.
  • Simple Statement: Cannot be broken down further (e.g., "5 > 3").
  • Compound Statement: Formed by combining simple statements using logical connectives.

Logical Connectives Table

Connective Symbol Example Note
Negation \(\neg p\) Not \(p\) Opposite truth value
Conjunction \(p \land q\) \(p\) AND \(q\) True only if both are True
Disjunction \(p \lor q\) \(p\) OR \(q\) True if at least one is True (Inclusive OR)
Exclusive OR \(p \oplus q\) Either \(p\) or \(q\) True if exactly one is True (Not both)
Implication \(p \to q\) If \(p\) then \(q\) False only if \(p=T\) and \(q=F\)
Bi-conditional \(p \leftrightarrow q\) \(p\) iff \(q\) True if \(p\) and \(q\) have the same value

Classification of Compound Propositions

Tautology (Valid)

A formula that is always True regardless of the truth values of its variables.

\(p \lor \neg p \equiv T\)

Contradiction

A formula that is always False.

\(p \land \neg p \equiv F\)

Contingency (Satisfiable)

Neither a tautology nor a contradiction. It is true for at least one assignment.

Note: All Valid formulas are Satisfiable, but not all Satisfiable formulas are Valid.

2. The Implication (\(\rightarrow\))

The statement \(p \to q\) is the most critical concept in logic reasoning.

Equivalent English Phrasings

  • If \(p\), then \(q\)
  • \(q\) if \(p\)
  • \(p\) only if \(q\)
  • \(p\) implies \(q\)
  • \(q\) when \(p\)
  • \(q\) whenever \(p\)
  • \(q\) follows from \(p\)
  • \(q\) unless \(\neg p\)
Key Equivalence: \(p \to q \equiv \neg p \lor q\)

Variations of \(p \to q\)

Name Formula Equivalence Note
Original \(p \to q\) Equivalent to Contrapositive
Converse \(q \to p\) Not equivalent to Original
Inverse \(\neg p \to \neg q\) Equivalent to Converse
Contrapositive \(\neg q \to \neg p\) Equivalent to Original (\(p \to q \equiv \neg q \to \neg p\))

3. Logical Equivalence Laws

Two formulas \(A\) and \(B\) are logically equivalent (\(A \equiv B\)) if they have the same truth values in all scenarios.

Important Laws

De Morgan's Laws

\(\neg (p \land q) \equiv \neg p \lor \neg q\)

\(\neg (p \lor q) \equiv \neg p \land \neg q\)

Distributive Laws

\(p \land (q \lor r) \equiv (p \land q) \lor (p \land r)\)

\(p \lor (q \land r) \equiv (p \lor q) \land (p \lor r)\)

Absorption Laws

\(p \lor (p \land q) \equiv p\)

\(p \land (p \lor q) \equiv p\)

Implication Laws

\(p \to q \equiv \neg p \lor q\)

\(p \to q \equiv \neg q \to \neg p\)

4. Inference Rules

Used to derive a conclusion from a set of premises. An argument is Valid if whenever premises are true, the conclusion is true.

graph TD A[Premises] --> B{Inference Rule} B --> C[Conclusion] subgraph Validity Check D[Assume Premises are TRUE] --> E[Check if Conclusion MUST be TRUE] end

Standard Rules

Rule Name Premises Conclusion Logic
Modus Ponens \(p \to q\), \(p\) \(\therefore q\) If \(p\) implies \(q\), and we have \(p\), we get \(q\).
Modus Tollens \(p \to q\), \(\neg q\) \(\therefore \neg p\) If \(p\) implies \(q\), and \(q\) is false, \(p\) must be false.
Hypothetical Syllogism \(p \to q\), \(q \to r\) \(\therefore p \to r\) Chaining implications.
Disjunctive Syllogism \(p \lor q\), \(\neg p\) \(\therefore q\) Elimination.
Resolution \(p \lor q\), \(\neg p \lor r\) \(\therefore q \lor r\) Canceling out \(p\) and \(\neg p\).

5. Predicate Logic & Quantifiers

Extends propositional logic by dealing with predicates \(P(x)\) and quantifiers over a domain \(D\).

Quantifiers

Universal Quantifier (\(\forall\))

"For all", "For every"

Notation: \(\forall x P(x)\)

True if \(P(x)\) is true for every \(x\) in Domain.

Analogy: Conjunction (\(\land\)) of all elements.

Existential Quantifier (\(\exists\))

"There exists", "For some"

Notation: \(\exists x P(x)\)

True if \(P(x)\) is true for at least one \(x\) in Domain.

Analogy: Disjunction (\(\lor\)) of all elements.

Negation of Quantifiers (De Morgan's for Logic)

\(\neg [\forall x P(x)] \equiv \exists x [\neg P(x)]\)

\(\neg [\exists x P(x)] \equiv \forall x [\neg P(x)]\)

Example: "Not all birds can fly" \(\equiv\) "There exists a bird that cannot fly".

6. Nested Quantifiers

When multiple quantifiers appear, the order matters. Let Domain \(D = \{1, 2, 3\}\).

Order of Operations

\(\forall x \forall y P(x,y)\) \(\equiv \forall y \forall x P(x,y)\) Order doesn't matter. All pairs must be True.
\(\exists x \exists y P(x,y)\) \(\equiv \exists y \exists x P(x,y)\) Order doesn't matter. At least one pair must be True.
\(\forall x \exists y P(x,y)\) \(\not\equiv \exists y \forall x P(x,y)\) Order Matters!

8. Proof Strategies & Rules

Inference with Quantifiers

  • Universal Instantiation (UI): If \(\forall x P(x)\) is true, then \(P(c)\) is true for any specific \(c\).
  • Universal Generalization (UG): If \(P(c)\) is true for an arbitrary \(c\), then \(\forall x P(x)\) is true.
  • Existential Instantiation (EI): If \(\exists x P(x)\) is true, then \(P(c)\) is true for some specific (new) constant \(c\).
  • Existential Generalization (EG): If \(P(c)\) is true for some \(c\), then \(\exists x P(x)\) is true.

Negation of Implications with Quantifiers

Statement: \(\forall x [P(x) \to Q(x)]\)

Negation: \(\neg \forall x [P(x) \to Q(x)]\)

\(\equiv \exists x \neg [P(x) \to Q(x)]\)

\(\equiv \exists x [P(x) \land \neg Q(x)]\)

Example: "All students pass" negated is "There exists a student who did NOT pass".
