1. Newton-Raphson Method

Used to find roots of transcendental (e.g., \(x e^x - 2 = 0\)) or algebraic equations. It is an open method requiring one initial guess.

The Formula

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

Where \(x_n\) is the current approximation and \(x_{n+1}\) is the next approximation.

Geometric Interpretation: Draw a tangent line at the point \((x_n, f(x_n))\). The point where this tangent cuts the x-axis becomes \(x_{n+1}\).

Process Visualized

Standard Cases (Memorize These)
Problem Function \(f(x)\) Iteration Formula
Square root of N (\(\sqrt{N}\)) \(x^2 - N = 0\) $$x_{n+1} = \frac{1}{2}\left(x_n + \frac{N}{x_n}\right)$$
Inverse of N (\(1/N\)) \(\frac{1}{x} - N = 0\) $$x_{n+1} = x_n(2 - N x_n)$$
k-th root of N (\(\sqrt[k]{N}\)) \(x^k - N = 0\) $$x_{n+1} = \frac{1}{k}\left((k-1)x_n + \frac{N}{x_n^{k-1}}\right)$$
Convergence: Newton-Raphson has Quadratic Convergence (Order 2). The error roughly squares at each step (\(\epsilon_{n+1} \propto \epsilon_n^2\)).

2. Numerical Integration

Approximating the definite integral \(I = \int_{a}^{b} f(x) dx\) by dividing the area into strips of width \(h\).

$$h = \frac{b - a}{n} \quad (\text{where } n = \text{number of sub-intervals})$$

Rule Comparison

Rule Polynomial Approximation Constraint Order of Error
Trapezoidal Linear (Straight line connecting points) Any number of intervals \(O(h^2)\)
Simpson's 1/3 Parabolic (2nd degree polynomial) Number of intervals (n) must be EVEN \(O(h^4)\) (Most Accurate)
Simpson's 3/8 Cubic (3rd degree polynomial) Number of intervals (n) must be multiple of 3 \(O(h^5)\)
Formulas

Let \(y_0, y_1, ..., y_n\) be values of \(f(x)\) at step points.

Trapezoidal Rule

$$\int_{x_0}^{x_n} y dx = \frac{h}{2} [ (y_0 + y_n) + 2(y_1 + y_2 + ... + y_{n-1}) ]$$

Sum of first and last + 2 times the sum of remaining.

Simpson's 1/3 Rule

$$\int_{x_0}^{x_n} y dx = \frac{h}{3} [ (y_0 + y_n) + 4(y_{odd}) + 2(y_{even}) ]$$

Sum of ends + 4(odd positions) + 2(even positions). Note: \(y_{odd}\) refers to \(y_1, y_3...\) excluding ends.

Simpson's 3/8 Rule

$$\int_{x_0}^{x_n} y dx = \frac{3h}{8} [ (y_0 + y_n) + 3(y_1+y_2+y_4+y_5...) + 2(y_3+y_6...) ]$$

Sum of ends + 3(non-multiples of 3) + 2(multiples of 3).

3. Solution of ODEs

Solving \(\frac{dy}{dx} = f(x, y)\) given \(y(x_0) = y_0\). Finding \(y\) at \(x = x_0 + h\).

Euler's Method (First Order)

The simplest, explicit forward method. Uses linear approximation.

$$y_{n+1} = y_n + h f(x_n, y_n)$$
  • Pros: Simple.
  • Cons: Large error, unstable for large step sizes.
  • Geometry: Follows the tangent slope at the beginning of the interval.

Runge-Kutta Method (4th Order)

The industry standard for accuracy. It calculates a weighted average of four slopes.

graph TD Start((Start x0, y0)) --> K1[k1 = h*f(x0, y0)] K1 --> K2[k2 = h*f(x0 + h/2, y0 + k1/2)] K2 --> K3[k3 = h*f(x0 + h/2, y0 + k2/2)] K3 --> K4[k4 = h*f(x0 + h, y0 + k3)] K4 --> Final[Weighted Sum] Final --> Formula[$$y_{n+1} = y_n + \frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$]
$$k_1 = h f(x_n, y_n)$$
$$k_2 = h f(x_n + \frac{h}{2}, y_n + \frac{k_1}{2})$$
$$k_3 = h f(x_n + \frac{h}{2}, y_n + \frac{k_2}{2})$$
$$k_4 = h f(x_n + h, y_n + k_3)$$
Runge-Kutta 2nd Order (Heun's Method)

Also known as the Improved Euler Method.

$$y_{n+1} = y_n + \frac{1}{2}(k_1 + k_2)$$

Where \(k_1 = hf(x_n, y_n)\) and \(k_2 = hf(x_n + h, y_n + k_1)\).

Summary & Exam Tips

⚠️ Common Mistakes

  • 👉 Calculator Mode: When dealing with trigonometric functions (sin, cos) inside numerical methods, ALWAYS set your calculator to RADIANS, not degrees.
  • 👉 Step Size (h): Always double check how \(h\) is defined. In integration, \(h = \frac{\text{Upper} - \text{Lower}}{\text{Segments}}\).
  • 👉 Simpson's Interval Count: If a question asks for Simpson's 1/3 rule with 5 data points, remember that 5 points = 4 intervals (Even). This is valid. 4 points = 3 intervals (Odd) is INVALID for Simpson's 1/3.
