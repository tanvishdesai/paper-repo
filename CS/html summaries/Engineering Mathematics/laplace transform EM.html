Laplace Transform

Comprehensive Engineering Mathematics Cheat Sheet for GATE/University Exams. Covers Definitions, Properties, Inverse Transforms, and Differential Equations.

1. Introduction & Definition

The Laplace Transform converts a function from the Time Domain (\(t\), real) to the Frequency Domain (\(s\), complex).

$$L[f(t)] = f(s) = \int_{0}^{\infty} e^{-st} f(t) dt$$
  • Domain: \(t \ge 0\) (Unilateral Laplace Transform)
  • Parameter: \(s = \sigma + j\omega\) (Complex number)
  • Condition: Integral must converge (function must be of exponential order).

3. Core Properties

Linearity Property

Laplace transform is a linear operator.

\(L[af(t) + bg(t)] = aF(s) + bG(s)\)

First Shifting Property

Multiplication by exponential \(e^{at}\) shifts the domain by \(a\).

If \(L[f(t)] = F(s)\), then:
\(L[e^{at}f(t)] = F(s-a)\)
Example: \(L[e^{-3t}\cos(4t)]\)
1. Find \(L[\cos(4t)] = \frac{s}{s^2 + 16}\)
2. Shift \(s \to s - (-3) = s+3\)
3. Result: \(\frac{s+3}{(s+3)^2 + 16}\)

Scaling Property

\(L[f(at)] = \frac{1}{a}F\left(\frac{s}{a}\right)\)

Multiplication by \(t^n\)

Corresponds to differentiation in \(s\)-domain.

\(L[t^n f(t)] = (-1)^n \frac{d^n}{ds^n} F(s)\)
Example: \(L[t \sin(t)]\)
1. \(F(s) = L[\sin t] = \frac{1}{s^2+1}\)
2. \(n=1\), so compute \(-\frac{d}{ds}\left(\frac{1}{s^2+1}\right)\)
3. Result: \(\frac{2s}{(s^2+1)^2}\)

Division by \(t\)

Corresponds to integration in \(s\)-domain.

\(L\left[\frac{f(t)}{t}\right] = \int_{s}^{\infty} F(u) du\)

Condition: \(\lim_{t \to 0} \frac{f(t)}{t}\) must exist.

Example: \(L\left[\frac{\sin t}{t}\right]\)
1. \(L[\sin t] = \frac{1}{s^2+1}\)
2. Integrate: \(\int_s^\infty \frac{1}{u^2+1} du\)
3. \([\tan^{-1} u]_s^\infty = \frac{\pi}{2} - \tan^{-1} s = \cot^{-1} s\)

4. Unit Step & Discontinuous Functions

Unit Step Function (Heaviside)

Defined as \(u(t-a)\) or \(H(t-a)\):

\(u(t-a) = \begin{cases} 0 & t < a \\ 1 & t \ge a \end{cases}\)

Transform:

\(L[u(t-a)] = \frac{e^{-as}}{s}\)

Second Shifting Property

Used for shifted functions multiplied by unit steps.

\(L[f(t-a)u(t-a)] = e^{-as}F(s)\)

Alternative Form:

\(L[g(t)u(t-a)] = e^{-as}L[g(t+a)]\)

Periodic Functions

If \(f(t) = f(t+T)\), then:

\(L[f(t)] = \frac{1}{1-e^{-sT}} \int_{0}^{T} e^{-st}f(t) dt\)

5. Inverse Laplace Transform

The goal is to find \(f(t)\) given \(F(s)\). Notation: \(L^{-1}[F(s)] = f(t)\).

Primary Methods

graph TD Start[Given F(s)] --> Check{Form Type} Check -->|Standard Form| Direct[Use Table directly] Check -->|Rational Function| PFD[Partial Fraction Decomposition] Check -->|Product of Functions| Convolution[Convolution Theorem] Check -->|Exponential e^-as| Shift[Second Shifting Property] Check -->|Logarithmic/Inverse Trig| Derivative[Derivative Property: L^-1[-F'(s)] = t f(t)]
Convolution Theorem:
\(L^{-1}[F(s)G(s)] = \int_{0}^{t} f(u)g(t-u) du = f(t) * g(t)\)
Example: Partial Fraction \(L^{-1}\left[\frac{1}{(s+1)(s+2)}\right]\)
1. Decompose: \(\frac{1}{(s+1)(s+2)} = \frac{A}{s+1} + \frac{B}{s+2}\)
2. Solve A, B: \(A=1, B=-1\)
3. New Form: \(\frac{1}{s+1} - \frac{1}{s+2}\)
4. Inverse: \(e^{-t} - e^{-2t}\)

6. Solving Differential Equations High Importance

Transforms of Derivatives

These are crucial for converting differential equations into algebraic equations.

\(L[f'(t)] = sF(s) - f(0)\)
\(L[f''(t)] = s^2F(s) - sf(0) - f'(0)\)
\(L[f'''(t)] = s^3F(s) - s^2f(0) - sf'(0) - f''(0)\)

Methodology Workflow

graph TD A[Differential Equation in t] -->|1. Take Laplace of both sides| B[Algebraic Equation in s] B -->|2. Substitute Initial Values| C[Simplify Equation] C -->|3. Solve for Y(s)| D[Y(s) = Some Function of s] D -->|4. Take Inverse Laplace| E[Solution y(t)]
Example: Solve \(y'' + 2y' - 3y = 0\), \(y(0)=1, y'(0)=2\)
Step 1: Transform
\([s^2Y(s) - sy(0) - y'(0)] + 2[sY(s) - y(0)] - 3Y(s) = 0\)

Step 2: Substitute Values
\((s^2Y - s(1) - 2) + 2(sY - 1) - 3Y = 0\)

Step 3: Isolate Y(s)
\(Y(s)(s^2 + 2s - 3) - s - 2 - 2 = 0\)
\(Y(s)(s^2 + 2s - 3) = s + 4\)
\(Y(s) = \frac{s+4}{(s+3)(s-1)}\)

Step 4: Partial Fractions & Inverse
\(\frac{s+4}{(s+3)(s-1)} = \frac{A}{s+3} + \frac{B}{s-1}\)
Using cover-up method: \(A = -1/4, B = 5/4\)
\(y(t) = -\frac{1}{4}e^{-3t} + \frac{5}{4}e^{t}\)
