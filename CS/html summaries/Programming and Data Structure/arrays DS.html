Array Properties

  • ✅ Contiguous Memory: Elements stored one after another.
  • ✅ Homogeneous: Stores similar types of elements.
  • ✅ Relative Addressing: Access via Base Address + Offset.
  • ✅ Random Access: $O(1)$ access time.
  • ⚠️ Fixed Size: Static memory allocation.

2. One-Dimensional (1D) Arrays

Maps a logical index to a physical memory address.

Address Calculation Formula $$Address(A[i]) = B.A + (i - LB) \times w$$

Variables Definition

  • B.A: Base Address (Address of 1st element)
  • i: Index of element to find
  • LB: Lower Bound (Start index, usually 0 or 1)
  • w: Width/Size of each element (in bytes)

Example: Negative Indexing

Given $A[-5 \dots 5]$, $w=2$ bytes, $B.A=1000$. Find $Addr(A[1])$.

$\text{LB} = -5$

$\text{Elements before } A[1] = 1 - (-5) = 6$

$Addr = 1000 + [1 - (-5)] \times 2$

$Addr = 1000 + 6 \times 2 = \mathbf{1012}$

3. Two-Dimensional (2D) Arrays

Memory is linear (1D). To store a 2D grid, we must flatten it. There are two standard methods:

Row Major Order (RMO)

Elements are stored row by row (Row 0, then Row 1, etc.). Standard in C/C++.

graph LR subgraph Matrix r0[Row 0] r1[Row 1] r2[Row 2] end subgraph Memory m1[Row 0] --> m2[Row 1] --> m3[Row 2] end r0 -.-> m1 r1 -.-> m2 r2 -.-> m3
RMO Formula $$Addr(A[i][j]) = B.A + [(i - L_r) \times N_c + (j - L_c)] \times w$$

where $N_c$ is Number of Columns per row.

Column Major Order (CMO)

Elements are stored column by column. Standard in Matlab/Fortran.

graph LR subgraph Matrix c0[Col 0] c1[Col 1] c2[Col 2] end subgraph Memory m1[Col 0] --> m2[Col 1] --> m3[Col 2] end c0 -.-> m1 c1 -.-> m2 c2 -.-> m3
CMO Formula $$Addr(A[i][j]) = B.A + [(j - L_c) \times N_r + (i - L_r)] \times w$$

where $N_r$ is Number of Rows per column.

How to calculate Number of Rows ($N_r$) and Columns ($N_c$)

If Array is defined as $A[LB_r \dots UB_r][LB_c \dots UB_c]$:

  • Number of Rows ($N_r$) = $UB_r - LB_r + 1$
  • Number of Columns ($N_c$) = $UB_c - LB_c + 1$

4. N-Dimensional Arrays

Generalizing the concept to 3D and beyond.

3D Array Address (Row Major)

For $A[L_1 \dots U_1][L_2 \dots U_2][L_3 \dots U_3]$ with dimensions size $S_1, S_2, S_3$.

To access $A[i][j][k]$:

$$Addr = B.A + [ (i-L_1) \cdot S_2 \cdot S_3 + (j-L_2) \cdot S_3 + (k-L_3) ] \times w$$

Logic: Skip full 2D planes ($S_2 \times S_3$) for index $i$, skip full rows ($S_3$) for index $j$, then add offset $k$.

5. Special Matrices & Optimization

Mapping specific patterns (Triangular, Diagonal) to 1D arrays to save memory (avoid storing zeros).

Lower Triangular Matrix (LTM)

Definition: $A_{ij} = 0$ if $i < j$. Non-zero elements are on and below the main diagonal.

Total Non-Zero Elements: $\frac{n(n+1)}{2}$

[ a11 0 0 0 ]
[ a21 a22 0 0 ]
[ a31 a32 a33 0 ]
[ a41 a42 a43 a44 ]
LTM Row Major Formula $$Addr(A_{ij}) = B.A + \left[ \frac{(i)(i-1)}{2} + (j-1) \right] \times w$$

*Assuming 1-based indexing for derivation. Logic: Sum of AP (1 + 2 + ... + i-1) rows filled completely before current row.

Upper Triangular Matrix (UTM)

Definition: $A_{ij} = 0$ if $i > j$. Non-zero elements are on and above the main diagonal.

[ a11 a12 a13 a14 ]
[ 0 a22 a23 a24 ]
[ 0 0 a33 a34 ]
[ 0 0 0 a44 ]
UTM Row Major Formula $$Addr(A_{ij}) = B.A + \left[ (i-1)N - \frac{(i-1)(i-2)}{2} + (j-i) \right] \times w$$

Logic: Total elements in full rows minus the "empty" triangle at the start of previous rows.

Tri-diagonal Matrix

Non-zero elements exist only on Main Diagonal ($i=j$), Sub-diagonal ($i=j+1$), and Super-diagonal ($i=j-1$).

Condition: $|i - j| \le 1$

Total Elements: $3n - 2$

Tri-diagonal Mapping $$Addr(A_{ij}) = B.A + [ 2(i-1) + (j-i+1) ] \times w$$

Logic: Each row $i$ (except first/last) contributes 3 elements. We calculate offset based on filled rows.
