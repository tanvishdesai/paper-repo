1. Fundamentals & Terminology

A tree is a non-linear data structure representing a hierarchical organization (e.g., Folder structure, Organization chart).

                    graph TD

                        A --> C((Child))
                        B --> D((Leaf))
                        B --> E((Leaf))

  • Root: The top-most node (no parent).
  • Leaf: Node with no children (Degree = 0).
  • Internal Node: Node with at least one child.
  • Sibling: Nodes sharing the same parent.
  • Degree of Node: Number of children.
  • Depth/Level: Distance from Root to Node (Root is Level 0).
  • Height of Node: Longest path from Node to a Leaf (Leaf height = 0).
  • Height of Tree: Height of the Root node.

2. Binary Trees

Definition: A tree where every node has at most 2 children (Left and Right).

Types of Binary Trees

Type Definition Key Property
Full / Strict Every node has either 0 or 2 children. No node has degree 1.
Complete (CBT) All levels filled completely, except possibly the last (filled left-to-right). Representable as an array without gaps.
Perfect All internal nodes have 2 children; all leaves are at the same level. Total nodes = \(2^{h+1} - 1\)
Skewed Every node has only one child (Left or Right). Height \(\approx\) Number of nodes.

Important Formulas

  • Max nodes in Binary Tree of height \(h\): $$N_{max} = 2^{h+1} - 1$$
  • Min nodes in Binary Tree of height \(h\): $$N_{min} = h + 1$$
  • Relationship (Full Binary Tree): Leaf Nodes (\(L\)) = Internal Nodes (\(I\)) + 1.
  • K-ary Tree Relationship: $$L = (K-1)I + 1$$

3. Tree Traversals

Traversing involves visiting every node in the tree exactly once.

                graph TD
                    A((1)) --> B((2))
                    A --> C((3))
                    B --> D((4))
                    B --> E((5))
                    C --> F((6))
                    C --> G((7))

Preorder (Root, L, R)

1, 2, 4, 5, 3, 6, 7

void pre(node *p) {
  if(!p) return;
  print(p->data);
  pre(p->left);
  pre(p->right);
}

Inorder (L, Root, R)

4, 2, 5, 1, 6, 3, 7

void in(node *p) {
  if(!p) return;
  in(p->left);
  print(p->data);
  in(p->right);
}

Postorder (L, R, Root)

4, 5, 2, 6, 7, 3, 1

void post(node *p) {
  if(!p) return;
  post(p->left);
  post(p->right);
  print(p->data);
}
Tree Reconstruction Rules:
  • Inorder + Preorder \(\rightarrow\) Unique Tree \(\checkmark\)
  • Inorder + Postorder \(\rightarrow\) Unique Tree \(\checkmark\)
  • Preorder + Postorder \(\rightarrow\) NOT Unique (unless it's a full binary tree).

4. Binary Search Trees (BST)

A binary tree where for every node X:
Values in Left Subtree < X < Values in Right Subtree.

Key Operations

  • Search: Compare key with root. If less, go left; if greater, go right. Cost: \(O(h)\).
  • Insertion: Always happens at a leaf position. Cost: \(O(h)\).
  • Deletion:
    • Leaf node: Just remove.
    • 1 Child: Replace node with its child.
    • 2 Children: Replace node with Inorder Predecessor (Max of Left Subtree) OR Inorder Successor (Min of Right Subtree).
Crucial Property: The Inorder traversal of a BST always yields the keys in sorted ascending order.

5. AVL Trees

A self-balancing Binary Search Tree. For every node, the height difference between left and right subtrees (Balance Factor) is at most 1.

$$BF = Height(Left) - Height(Right) \in \{-1, 0, 1\}$$

Rotations

Rotations fix imbalance after insertion/deletion.

  • LL Rotation: Single Right Rotation.
  • RR Rotation: Single Left Rotation.
  • LR Rotation: Left Rotation on Child, then Right on Root (Double).
  • RL Rotation: Right Rotation on Child, then Left on Root (Double).

Min Nodes for Height h

To create the "sparest" AVL tree (max height for min nodes), we follow the recurrence:

$$N(h) = N(h-1) + N(h-2) + 1$$

This relates closely to Fibonacci numbers.

6. Heaps

A Heap is a Complete Binary Tree (CBT) satisfying the heap property.

Max-Heap

Root \(\ge\) Children. Max element is at the root.

Min-Heap

Root \(\le\) Children. Min element is at the root.

Array Representation (1-based index)

For a node at index \(i\):

  • Left Child: \(2i\)
  • Right Child: \(2i + 1\)
  • Parent: \(\lfloor i/2 \rfloor\)

Operations

Operation Complexity Description
Find Max (Max-Heap) \(O(1)\) Return A[1].
Insert \(O(\log n)\) Add at end, then "Bubble Up" (Up-Heapify).
Delete Max \(O(\log n)\) Replace Root with last element, then "Bubble Down" (Heapify).
Build Heap \(O(n)\) Tight bound is linear, not \(n \log n\).

7. Counting Trees

How many structurally unique binary trees can be formed with \(n\) nodes?

Catalan Number

$$T(n) = \frac{1}{n+1} \binom{2n}{n} = \frac{(2n)!}{(n+1)!n!}$$

Scenarios:

  • Unlabeled Binary Trees: Catalan Number.
  • Labeled Binary Trees: Catalan Number \(\times n!\).
  • Binary Search Trees (BST) with n distinct keys: Catalan Number (Structure dictates position).

Example for \(n=3\): \(\frac{1}{4}\binom{6}{3} = \frac{20}{4} = 5\) trees.

8. Expression Trees

Leaves are operands, internal nodes are operators.

                graph TD
                    plus((+)) --> a((a))
                    plus --> mult(( * ))
                    mult --> b((b))
                    mult --> c((c))

Expression: \(a + (b \times c)\)

  • Inorder Traversal: Infix Expression.
  • Preorder Traversal: Prefix Expression (Polish Notation).
  • Postorder Traversal: Postfix Expression (Reverse Polish).
