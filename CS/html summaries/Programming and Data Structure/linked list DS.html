1. Fundamentals of Linked List

Definition

A linear data structure where elements are not stored in contiguous memory locations. Elements are linked using pointers.

graph LR A[Head: 1000] -->|Points to| B(Node 1) subgraph Node 1 [Address: 1000] D1[Data: 10] --- N1[Next: 2000] end N1 -->|Points to| C(Node 2) subgraph Node 2 [Address: 2000] D2[Data: 20] --- N2[Next: NULL] end

Structure & Memory

A Self-Referential Structure is used to define a node.

struct Node {
    int data;              // 4 bytes
    struct Node *next;     // 4 or 8 bytes (pointer)
};
Memory Allocation: Nodes are allocated in the Heap memory using malloc during runtime (Dynamic Memory Allocation).
struct Node *temp = (struct Node*)malloc(sizeof(struct Node));

Array vs Linked List

Feature Array Linked List
Memory Contiguous (Stack/Data segment) Non-contiguous (Heap)
Size Fixed (Static) Dynamic (grows/shrinks)
Access Random Access \(O(1)\) Sequential Access \(O(n)\)
Insertion/Deletion Costly \(O(n)\) (Shifting required) Efficient \(O(1)\) (if pointer known)

2. Basic Operations

Traversal

Iterating through the list until the next pointer is NULL.

void traverse(struct Node *head) {
    struct Node *ptr = head;
    while (ptr != NULL) {
        printf("%d ", ptr->data);
        ptr = ptr->next; // Move to next node
    }
}

Counting Nodes

Initialize a counter and increment while traversing.

int countNodes(struct Node *head) {
    int count = 0;
    struct Node *ptr = head;
    while (ptr != NULL) {
        count++;
        ptr = ptr->next;
    }
    return count;
}

Insertion

Show Implementation Code 
struct Node* insertAtBegin(struct Node *head, int data) {
    struct Node *temp = malloc(sizeof(struct Node));
    temp->data = data;
    temp->next = head;  // Point new node to current head
    head = temp;        // Update head to new node
    return head;
}

Deletion

Always check for Underflow: Before deleting, check if (head == NULL). If true, the list is empty.

Deleting a specific node (logic):

  1. Traverse to find the node before the target (prev).
  2. Link prev->next to curr->next.
  3. Free the memory of curr.

4. The "Two Pointer" Magic Crucial

Many efficiency problems are solved using slow and fast pointers.

1. Finding the Middle Element

Logic: Move slow by 1 step, fast by 2 steps. When fast reaches the end, slow is at the middle.

Slow = Slow->next;
Fast = Fast->next->next;

Stop Condition:

  • Odd nodes: fast->next == NULL
  • Even nodes: fast == NULL

2. Cycle Detection (Floyd's Algorithm)

If slow and fast pointers ever meet, there is a loop.

graph LR A --> B --> C --> D --> E --> C style C fill:#fef9c3 style E fill:#fef9c3 linkStyle 4 stroke:red,stroke-width:2px; 
while (fast != NULL && fast->next != NULL) {
    slow = slow->next;
    fast = fast->next->next;
    if (slow == fast) return true; // Cycle detected
}

5. Advanced Problems

Intersection Point of 2 Linked Lists

Method:

  1. Count nodes in List A (\(C_1\)) and List B (\(C_2\)).
  2. Calculate difference \(d = |C_1 - C_2|\).
  3. Move the pointer of the longer list \(d\) steps forward.
  4. Move both pointers together until they collide.

Merge Two Sorted Lists

Create a dummy node or use recursion to weave the lists together.

if (a->data < b->data) {
    head = tail = a;
    a = a->next;
} else {
    head = tail = b;
    b = b->next;
}
