1. Boolean Algebra Fundamentals

Boolean algebra is the mathematical foundation of digital circuits. It operates on binary variables (0 and 1).

Law Name Expression (AND form) Expression (OR form)
Annulment $A \cdot 0 = 0$ $A + 1 = 1$
Identity $A \cdot 1 = A$ $A + 0 = A$
Idempotent $A \cdot A = A$ $A + A = A$
Complement $A \cdot \bar{A} = 0$ $A + \bar{A} = 1$
Double Negation $\overline{\overline{A}} = A$
Absorption $A(A+B) = A$ $A + AB = A$
💡 Important Reduction:
$A + \bar{A}B = A + B$
Logic: The $\bar{A}$ is redundant because if A is 1, the term is 1. If A is 0, the second term becomes $1 \cdot B$.

2. Critical Minimization Theorems

De Morgan's Law

Crucial for converting between NAND/NOR logic.

$\overline{A \cdot B} = \bar{A} + \bar{B}$
$\overline{A + B} = \bar{A} \cdot \bar{B}$

Consensus Theorem

Used to eliminate redundant terms. The term that lacks the complemented variable is the consensus (redundant) term.

$AB + \bar{A}C + BC = AB + \bar{A}C$

Identification: Look for 3 variables where each appears twice, and one variable is complemented. The term without the complemented variable ($BC$) is redundant.

Transpose Theorem

$(A + B)(A + C) = A + BC$
$(A + B)(\bar{A} + C) = AC + \bar{A}B$

4. Logic Gates & Realization

XOR & XNOR Properties

Essential for arithmetic circuits and parity checkers.

  • XOR ($\oplus$): Output 1 if inputs are different. (Odd function)
  • XNOR ($\odot$): Output 1 if inputs are same. (Even function)
$A \oplus A = 0$  |  $A \oplus \bar{A} = 1$  |  $A \oplus 0 = A$  |  $A \oplus 1 = \bar{A}$
Controlled Inverter: An XOR gate with one input tied to logic '1' acts as an inverter for the other input.

Universal Gates

Any Boolean function can be implemented using only NAND or only NOR gates.

  • NAND: AND followed by NOT. Bubble at output.
  • NOR: OR followed by NOT. Bubble at output.

5. Karnaugh Maps (K-Maps)

A graphical method to minimize Boolean functions. Uses Gray Code ordering (00, 01, 11, 10) so adjacent cells differ by only 1 bit.

The "CJ Baba Rule"

Golden Rule: Always form the largest possible group ($2^n$).
Larger Group = Fewer Literals in the final expression.
  • 1 cell group = n variables
  • 2 cell group (Pair) = n-1 variables
  • 4 cell group (Quad) = n-2 variables
  • 8 cell group (Octet) = n-3 variables

Don't Care Conditions ($\phi$ or X)

Input combinations that never occur or output states that don't matter.

  • Can be treated as 0 or 1 to help form larger groups.
  • Do not need to be covered if they don't help enlarge a group of 1s.

6. Classification of Implicants

When analyzing a K-Map, groups are classified as follows:

Term Definition Visual Clue
Implicant (I) Any single minterm (1) or valid group of 1s (pair, quad, etc.). Any rectangle of 1s.
Prime Implicant (PI) A group that is not fully contained within a larger group. It is "maximal." The biggest possible circles you can draw.
Essential Prime Implicant (EPI) A PI that contains at least one '1' that is not covered by any other PI. A circle containing a '1' that has no other circle overlapping it. Must appear in final answer.
Redundant Prime Implicant (RPI) A PI whose 1s are all covered by other EPIs. Needed for logic cover but not unique.
Selective Prime Implicant (SPI) PIs that are not essential but needed to cover remaining 1s. Usually creates multiple valid solutions.

Implicant Hierarchy

7. Common Edge Cases

  • Number of Functions: For $n$ variables, there are $2^{2^n}$ possible boolean functions.
  • Minterms/Maxterms Count: For $n$ variables, there are $2^n$ minterms and $2^n$ maxterms.
  • Two-Way Switch: This is an example of XOR logic (staircase switch).
  • Static Hazard: Occurs in a circuit when adjacent 1s in a K-Map are not grouped together (Redundant grouping fixes this).
