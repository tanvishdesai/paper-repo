1. Fundamentals & The Inverter

NOT Gate (Inverter)

Operation: Inverts the input signal. $Y = \bar{A}$

Properties:

  • $A \cdot \bar{A} = 0$
  • $A + \bar{A} = 1$

Buffer

Operation: Passes signal unchanged. Used for delay or amplification. $Y = A$

Chain Rule:

  • Even Inverters = Buffer
  • Odd Inverters = Inverter

Propagation Delay & Ring Oscillators

Propagation Delay ($\tau_{pd}$): Time taken for the output to respond to input change.

Case A: Odd Number of NOT Gates

Astable Multivibrator

Feedback with odd inverters creates oscillation.

graph LR A[NOT] --> B[NOT] B --> C[NOT] C --> A

Output: Square Wave (Clock Generator)

Formulas:

$$ T = 2 \times N \times \tau_{pd} $$ $$ f_{osc} = \frac{1}{2 \times N \times \tau_{pd}} $$ Where $N$ is the (odd) number of gates.

Case B: Even Number of NOT Gates

Bistable Multivibrator

Feedback with even inverters holds state.

graph LR A[NOT] --> B[NOT] B --> A

Output: Stable State (Basic Memory Element)

Frequency: $f = 0$ Hz (DC Generator)

2. Basic Gates (AND / OR)

AND Gate (Intersection)

Expression: $Y = A \cdot B$

Logic: High only if ALL inputs are High.

Properties & Control
  • Enable/Disable:
    • Control `0`: Output fixed at `0` (Disable)
    • Control `1`: Output follows Input (Enable)
  • Unused Inputs: Float High (TTL) or Pulled Up.
  • Commutative: $A \cdot B = B \cdot A$ ✅
  • Associative: $(A \cdot B) \cdot C = A \cdot (B \cdot C)$ ✅

OR Gate (Union)

Expression: $Y = A + B$

Logic: High if ANY input is High.

Properties & Control
  • Enable/Disable:
    • Control `1`: Output fixed at `1` (Disable)
    • Control `0`: Output follows Input (Enable)
  • Unused Inputs: Float Low (ECL) or Pulled Down.
  • Commutative: $A + B = B + A$ ✅
  • Associative: $(A + B) + C = A + (B + C)$ ✅

3. Universal Gates (NAND / NOR)

Called "Universal" because any boolean function can be realized using only NAND or only NOR gates.

NAND Gate

Logic: AND followed by NOT. $Y = \overline{A \cdot B}$

Bubbled OR: $\overline{A \cdot B} = \bar{A} + \bar{B}$

Associative: ❌ No

Commutative: ✅ Yes

Control: Input `0` forces output `1` (Disable).

NOR Gate

Logic: OR followed by NOT. $Y = \overline{A + B}$

Bubbled AND: $\overline{A + B} = \bar{A} \cdot \bar{B}$

Associative: ❌ No

Commutative: ✅ Yes

Control: Input `1` forces output `0` (Disable).


Shortcuts: Gate Realization Minimization

Formula to calculate minimum Universal Gates required for N-variable expression.

Target Function Using NAND Using NOR
Case 1: $A \cdot B \cdot C \dots$ (Product) $(2n - 2) + k$ $(3n - 3) - k$
Case 2: $A + B + C \dots$ (Sum) $(3n - 3) - k$ $(2n - 2) + k$
Note $n$ = Total variables, $k$ = Complemented variables

Example: For $f = \bar{A}BC$ using NAND ($n=3, k=1$): $(2(3)-2)+1 = 5$ Gates.

4. Arithmetic & Special Gates (XOR / XNOR)

XOR Gate (Inequality Detector)

Symbol: $\oplus$

Expression: $Y = A \oplus B = \bar{A}B + A\bar{B}$

Logic: High if inputs are different.

Function: Odd Parity Detector.

Control Input Mode:
$A \oplus 0 = A$ (Buffer)
$A \oplus 1 = \bar{A}$ (Inverter)

XNOR Gate (Equality Detector)

Symbol: $\odot$

Expression: $Y = A \odot B = AB + \bar{A}\bar{B}$

Logic: High if inputs are same.

Function: Even Parity Detector / Coincidence Logic.

Control Input Mode:
$A \odot 0 = \bar{A}$ (Inverter)
$A \odot 1 = A$ (Buffer)

Multi-Variable Properties

XOR Chain (Odd number of 1s detector)

Output is High if the number of 1s in input is ODD.

XNOR Chain

Odd Variables: Same as XOR chain ($A \odot B \odot C = A \oplus B \oplus C$)

Even Variables: Inverse of XOR chain.

5. Logic Families & Implementation Details

Family Name Floating Input Behavior Key Feature
TTL Transistor-Transistor Logic Acts as Logic 1 (High) Standard legacy logic.
ECL Emitter Coupled Logic Acts as Logic 0 (Low) Fastest logic family, high power.
CMOS Complementary MOS Unpredictable (Must assume neither) Low power, high density.
Transistor / Diode Implementation Circuits

Diode Logic (DL)

  • AND: Diodes facing OUT towards inputs. Input Low pulls node Low.
  • OR: Diodes facing IN from inputs. Input High pushes node High.

Transistor Logic (Inverter)

  • Input High (1): Transistor ON $\rightarrow$ Short to Ground $\rightarrow$ Output Low (0).
  • Input Low (0): Transistor OFF $\rightarrow$ Open Circuit $\rightarrow$ Output Pulled High (1).
