Digital Logic: Combinational Circuits

Comprehensive study guide covering Arithmetic Circuits, MUX, Decoders, Encoders, and their implementations.

1. Basics of Combinational Circuits

A combinational circuit is a memoryless digital logic circuit whose output depends only on the current combination of inputs.

Characteristics

  • Memory: None (No feedback path).
  • Clock: Not required (Static circuit).
  • Building Blocks: Logic Gates (AND, OR, NOT, NAND, NOR, XOR, XNOR).
  • Analysis: Truth Table \(\rightarrow\) Boolean Expression \(\rightarrow\) Circuit.

Design Steps

  1. Identify number of Inputs and Outputs.
  2. Create the Truth Table.
  3. Derive Boolean Expressions (K-Map).
  4. Minimize Expressions.
  5. Draw Logic Diagram.

2. Arithmetic Circuits

Fundamental circuits for binary addition and subtraction.

Half Adder (HA)

Adds two single bits ($A, B$). Produces Sum ($S$) and Carry ($C$).


Equations:
$$ S = A \oplus B = \bar{A}B + A\bar{B} $$ $$ C = A \cdot B $$
Gate Requirements:
  • Min NAND Gates: 5
  • Min NOR Gates: 5
graph LR A((A)) --> XOR B((B)) --> XOR A --> AND B --> AND XOR[XOR] --> S((Sum)) AND[AND] --> C((Carry))
Full Adder (FA)

Adds three single bits ($A, B, C_{in}$). Needed for cascading adders.


Equations:
$$ S = A \oplus B \oplus C_{in} $$ $$ C_{out} = AB + BC_{in} + AC_{in} $$ $$ C_{out} = (A \oplus B)C_{in} + AB $$
Gate Requirements:
  • Implemented using 2 Half Adders + 1 OR Gate.
  • Min NAND/NOR Gates: 9

3. Parallel & Look Ahead Carry Adder

Ripple Carry Adder (RCA)

Cascading $n$ Full Adders to add two $n$-bit numbers. The carry ripples from LSB to MSB.

graph LR FA0[FA0] -->|C1| FA1[FA1] FA1 -->|C2| FA2[FA2] FA2 -->|C3| FA3[FA3] FA3 --> C4((Cout)) style FA0 fill:#f9f,stroke:#333 style FA1 fill:#f9f,stroke:#333 style FA2 fill:#f9f,stroke:#333 style FA3 fill:#f9f,stroke:#333
Worst Case Delay ($T_{RCA}$):
$$ T = (n-1)T_{carry} + \max(T_{sum}, T_{carry}) $$
If using HA decomposition internally:
$$ T \approx 2n \times T_{gate} \quad \text{(Linear Growth } O(n)\text{)} $$

Look Ahead Carry Adder (LACA)

Overcomes the delay of RCA by calculating carry signals in advance using Carry Generate ($G$) and Carry Propagate ($P$) logic.

Terms:
  • $P_i = A_i \oplus B_i$ (Carry Propagate)
  • $G_i = A_i \cdot B_i$ (Carry Generate)

Carry Equations:
  • $C_{i+1} = G_i + P_i C_i$
  • $C_1 = G_0 + P_0 C_0$
  • $C_2 = G_1 + P_1 G_0 + P_1 P_0 C_0$
Advantages:
  • Speed Constant delay $O(1)$ theoretically (typically 2-level gate delay for Carry Block).
  • Complexity Hardware complexity increases exponentially with $n$.

4. Magnitude Comparators

Circuits that compare two binary numbers $A$ and $B$.

1-Bit Comparator

Logic Expressions:
  • $A > B \Rightarrow X = A\bar{B}$
  • $A < B \Rightarrow Y = \bar{A}B$
  • $A = B \Rightarrow Z = A \odot B$ (XNOR)
Conditions count for n-bits:
  • Total combinations: $2^{2n}$
  • Equal cases: $2^n$
  • Greater/Less cases: $\frac{2^{2n} - 2^n}{2}$

Cascading for N-bits

To compare Higher Order bits, we check lower order only if higher order bits are equal.

$$(A>B)_{total} = (A_n > B_n) + (A_n = B_n)(A_{n-1} > B_{n-1}) + \dots $$

5. Multiplexers (MUX)

Also known as "Data Selector". It selects one of the $2^n$ inputs and routes it to the single output based on $n$ select lines.

Properties

  • Formula: $2^n \times 1$ MUX has $n$ select lines.
  • Equation (4x1): $$Y = \bar{S}_1\bar{S}_0 I_0 + \bar{S}_1 S_0 I_1 + S_1\bar{S}_0 I_2 + S_1 S_0 I_3$$
  • Universal Logic: Can implement any Boolean function.
graph TB I0 --> Mux I1 --> Mux I2 --> Mux I3 --> Mux Sel[Select Lines S1, S0] --> Mux Mux{4x1 MUX} --> Y

Implementation Methods

Implementing function $f(A,B,C) = \sum m(0, 1, 4, 7)$ using MUX.

Method MUX Size Select Lines Procedure
Type 1 $2^n \times 1$ $n$ (All vars) Connect Logic 1 to minterms, Logic 0 to maxterms.
Type 2 $2^{n-1} \times 1$ $n-1$ vars Use the remaining variable (and its complement) as Data Inputs. (Implementation Table).

MUX Tree (Cascading)

To design a $16 \times 1$ MUX using $4 \times 1$ MUXes:

$$ \text{Formula: } \frac{N}{n} + \frac{\text{Result}}{n} + \dots $$ $$ \frac{16}{4} = 4 \rightarrow \frac{4}{4} = 1 \implies \text{Total } 4 + 1 = 5 \text{ MUXes} $$

6. Decoders & De-Multiplexers

Decoder ($n \times 2^n$)

Decodes $n$ inputs to activate one of $2^n$ outputs (Minterms).

  • Active High: Output is 1 for selected code (AND gates).
  • Active Low: Output is 0 for selected code (NAND gates).
  • Use Case: Memory addressing, Function implementation (Decoder + OR gate).

De-Multiplexer ($1 \times 2^n$)

Data Distributor. Routes 1 input to one of $2^n$ outputs.

  • Structurally identical to a Decoder with an Enable input acting as the Data input.

Logic Implementation

To implement $f(A,B,C) = \sum m(1, 3, 7)$:
1. Use a $3 \times 8$ Decoder.
2. Take outputs 1, 3, and 7.
3. Connect them to an OR gate.

7. Encoders

Converts $2^n$ (or fewer) input lines into an $n$-bit code. Opposite of a decoder.

Priority Encoder

Standard encoders fail if multiple inputs are active. Priority encoders output the code for the highest priority active input.

Code Converters

Encoders can design converters like Binary to Gray, BCD to Excess-3, etc.

  • Binary to Gray: $G_n = B_n$, $G_i = B_{i+1} \oplus B_i$
  • Excess-3: BCD + 0011 (3). Self-complementing code.
