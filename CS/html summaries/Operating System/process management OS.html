1. Execution Modes & System Calls

Dual Mode Operation

The CPU operates in two primary modes to ensure protection and stability. Mode switching involves changing the Mode Bit in the Processor Status Word (PSW).

  • User Mode (Bit = 1): Restricted access. Non-privileged instructions only. Crashes here are recoverable.
  • Kernel Mode (Bit = 0): Privileged mode. Full hardware access. Runs OS code. Crashes here are catastrophic.

2. Process Concepts

Program vs. Process

Program: Passive entity. Executable file stored on disk (Code).

Process: Active entity. An instance of a program in execution. Contains Program Counter (PC) and associated resources.

Process Control Block (PCB)

The "Identity Card" of the process. Stored in Kernel Memory.

  • 🪪 PID: Process Identifier
  • 🔢 Program Counter: Address of next instruction
  • 🚦 State: Ready, Running, Blocked, etc.
  • 💾 Registers: Accumulators, Index registers
  • 📅 Scheduling Info: Priority, pointers to queues
  • 🧠 Memory Limits: Base and Limit registers
  • 📂 I/O Info: List of open files

3. Process State Transitions

The lifecycle of a process from creation to termination. The OS moves processes between queues based on these states.

Main States

  • New: Process is being created.
  • Ready: In main memory, waiting for CPU.
  • Running: Instructions are being executed. (Max # = # of CPUs).
  • Blocked (Wait): Waiting for I/O or event completion.
  • Terminated: Finished execution. Resources deallocated.

Suspended States (Swapped Out)

Used when main memory is full.

  • Suspend Ready: Ready to run but swapped to disk (Backing Store).
  • Suspend Wait: Blocked on I/O and swapped to disk.

4. Scheduling & Queues

Process Scheduling handles the selection of processes to run on the CPU.

Types of Schedulers

Scheduler Name Queue Function & Frequency
LTS Long Term Job Queue → Ready Queue Controls Degree of Multiprogramming. Loads process from disk to memory. Infrequent.
STS Short Term Ready Queue → CPU Selects which process runs next. Also called CPU Scheduler. Very Frequent.
MTS Medium Term Memory ↔ Disk Performs Swapping (Suspend/Resume). Reduces degree of multiprogramming when RAM is full.

Scheduling Queues

Ready Queue: Usually implemented as a Linked List of PCBs.

Device Queue: Each device has its own queue for blocked processes.

5. Context Switching

Context Switch: The process of saving the state (PCB) of the old process and loading the saved state of the new process.

  • Pure overhead (system does no useful work while switching).
  • Heavily dependent on hardware support.

Dispatcher: The module that gives control of the CPU to the process selected by the Short Term Scheduler.

  • Function: Switch context, Switch to User Mode, Jump to PC location.
Dispatch Latency

Time taken by the dispatcher to stop one process and start another running.

6. Process Times & Formulas

Criteria for comparing scheduling algorithms.

Definitions
  • Arrival Time (AT): Time process enters Ready Queue.
  • Burst Time (BT): Time required by process on CPU.
  • Completion Time (CT): Time process completes execution.
  • Turnaround Time (TAT): Total time spent in the system (Submission to Completion).
  • Waiting Time (WT): Total time spent waiting in the Ready Queue.
Key Formulas
$$ TAT = CT - AT $$ $$ WT = TAT - BT $$ $$ WT = TAT - (BT + I/O\_Burst) $$

Goal: Maximize CPU Utilization & Throughput. Minimize TAT, WT, and Response Time.
