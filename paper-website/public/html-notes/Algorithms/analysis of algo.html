1. Fundamentals of Algorithms

Definition & Characteristics

An algorithm is a finite set of steps/statements to solve a specific problem. It corresponds to an abstract machine processing logic.

  • Input: Zero or more inputs.
  • Output: At least one output.
  • Definiteness: Each instruction is clear and unambiguous.
  • Finiteness: Must terminate after a finite number of steps.
  • Effectiveness: Operations must be basic enough to be carried out.

2. Asymptotic Notations (ASN)

ASN is the mathematical tool used in Priori Analysis to represent the bounding behavior of a function as input size \( n \to \infty \).

1. Big Oh (O) - Upper Bound (Worst Case)

\( f(n) = O(g(n)) \) iff there exist constants \( c > 0 \) and \( n_0 \ge 1 \) such that:
$$ f(n) \le c \cdot g(n) \quad \forall n \ge n_0 $$

Meaning: \( f(n) \) grows no faster than \( g(n) \). It describes the "ceiling" of resource usage.

2. Big Omega (\(\Omega\)) - Lower Bound (Best Case)

\( f(n) = \Omega(g(n)) \) iff there exist constants \( c > 0 \) and \( n_0 \ge 1 \) such that:
$$ f(n) \ge c \cdot g(n) \quad \forall n \ge n_0 $$

Meaning: \( f(n) \) grows at least as fast as \( g(n) \). It describes the "floor" of resource usage.

3. Theta (\(\Theta\)) - Tight Bound (Average/Exact)

\( f(n) = \Theta(g(n)) \) iff there exist constants \( c_1, c_2 > 0 \) and \( n_0 \ge 1 \) such that:
$$ c_1 \cdot g(n) \le f(n) \le c_2 \cdot g(n) \quad \forall n \ge n_0 $$

Meaning: \( f(n) \) grows at the same rate as \( g(n) \).

Small oh (\(o\)) - Loose Upper Bound

Strictly less than. \( f(n) < c \cdot g(n) \). Example: \( n = o(n^2) \) is True, but \( n = o(n) \) is False.

Small omega (\(\omega\)) - Loose Lower Bound

Strictly greater than. \( f(n) > c \cdot g(n) \). Example: \( n^2 = \omega(n) \) is True.

3. Growth Rates & Dominance

To analyze algorithms, we compare the rate of growth of functions. The hierarchy of complexity is crucial for solving problems.

The Dominance Chain:

\( 1 < \log(\log n) < \log n < \sqrt{n} < n < n \log n < n^2 < n^3 < \dots < 2^n < n! < n^n \)

Key Comparisons

  • Logarithms: \( \log_a n \) and \( \log_b n \) are asymptotically the same (\( \Theta \)) because they differ only by a constant multiplier.
  • Polynomials: For \( a_k n^k + \dots \), the term with the highest power \( k \) dominates. Lower order terms are ignored.
  • Exponentials: \( 2^n \) is significantly faster growing than \( n^{100} \) for large \( n \). Note: \( 2^n \ne O(2^{n+1}) \) is incorrect; actually \( 2^{n+1} = 2 \cdot 2^n = O(2^n) \). However, \( 2^{2n} = 4^n \neq O(2^n) \).

Helpful Math Identities

  • \( \log(ab) = \log a + \log b \)
  • \( a^{\log_b n} = n^{\log_b a} \) (Swap property)
  • Sum of 1 to n: \( \frac{n(n+1)}{2} = \Theta(n^2) \)
  • Sum of Geometric Series (\(r > 1\)): \( \frac{a(r^n - 1)}{r-1} = \Theta(r^n) \) (Last term dominates)

4. Analyzing Non-Recursive Algorithms (Loops)

General Rules

  1. Simple Loops: Determine the number of iterations.
  2. Nested Loops: Multiply the complexities (if independent) or sum the series (if dependent).
  3. Consecutive Loops: Take the maximum (Add complexities).

Common Patterns

Linear Loop

for(i=1; i<=n; i++) {
    // const work
}

Complexity: \( O(n) \)

Logarithmic Loop (Multiply/Divide)

for(i=1; i<=n; i = i*2) {
    // const work
}

Complexity: \( O(\log_2 n) \)

Dependent Nested Loop

for(i=1; i<=n; i++) {
   for(j=1; j<=i; j++) {
      // work
   }
}

Executes \( 1 + 2 + 3 + \dots + n \).

Complexity: \( O(n^2) \)

Root Loop

for(i=1; i*i <= n; i++) {
    // const work
}

Stops when \( i^2 = n \implies i = \sqrt{n} \).

Complexity: \( O(\sqrt{n}) \)

5. Analyzing Recursive Algorithms

Time complexity for recursion is derived by solving Recurrence Relations.

Method 1: Substitution / Recursion Tree

Example: \( T(n) = 2T(n/2) + n \) (Merge Sort structure)

graph TD Root(n) --> L(n/2) Root --> R(n/2) L --> L1(n/4) L --> L2(n/4) R --> R1(n/4) R --> R2(n/4)

Total work = (Work per level) × (Number of levels).

Work per level is \( cn \). Height is \( \log_2 n \).

Result: \( O(n \log n) \)

Method 2: Master Theorem (Quick Ref)

For recurrences of form \( T(n) = aT(n/b) + f(n) \):

  • Compare \( n^{\log_b a} \) with \( f(n) \).
  • Case 1: If \( n^{\log_b a} > f(n) \), then \( T(n) = \Theta(n^{\log_b a}) \).
  • Case 2: If \( n^{\log_b a} = f(n) \), then \( T(n) = \Theta(n^{\log_b a} \log n) \).
  • Case 3: If \( n^{\log_b a} < f(n) \), then \( T(n) = \Theta(f(n)) \) (provided regularity condition holds).

6. Space Complexity

Space Complexity = Input Space (to store data) + Auxiliary Space (extra space used by algo).

Memory Stack in Recursion

Recursive algorithms use the system stack to store activation records (local variables, return address) for each function call.

  • Formula: \( \text{Space} \propto \text{Max Depth of Recursion Tree} \).

Example:

void test(n) {
    if (n <= 0) return;
    test(n-1);
}

Input size: \( O(1) \). Auxiliary Space: \( O(n) \) (Depth of stack).
