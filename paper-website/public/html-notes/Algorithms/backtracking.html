Backtracking & Branch and Bound

Comprehensive Cheat Sheet based on CS & IT Engineering Notes by Dr. Khaleel Khan

Overview

These are general techniques for solving problems that require searching for a set of solutions or an optimal solution satisfying specific constraints.

Backtracking

Builds candidates for the solution incrementally and abandons a candidate ("backtracks") as soon as it determines that the candidate cannot possibly be completed to a valid solution.

Branch & Bound

Similar to backtracking but usually used for optimization problems. It uses a bounding function to prune branches of the state-space tree that cannot yield a better solution than the one already found.

1. Backtracking Framework

First coined by D.H. Lehmer (1950s). The solution is typically expressed as an n-tuple \( \langle x_1, x_2, ..., x_n \rangle \) chosen from a finite set \( S_i \).

Backtracking = DFS + Bounding Functions

The goal is often to find a vector that maximizes, minimizes, or satisfies a criterion function \( P(x_1, ... x_n) \).

2. State-Space Trees

The tree organization of the solution space. Nodes are numbered as in Depth First Search (DFS).

Fixed Tuple Size

Example: N-Queens. Every solution has exactly \( n \) components.

Tree Depth = \( n \)

Variable Tuple Size

Example: Sum of Subsets. Solutions can have varying lengths.

Tree Depth varies based on selection.
Visualizing the Pruning Process

When a node is reached, the Bounding Function checks if it can lead to a valid solution. If not, the node is "killed" (bounded), and we backtrack to the parent.

3. The N-Queens Problem

Place \( n \) queens on an \( n \times n \) chessboard so that no two queens attack each other (no shared row, column, or diagonal).

Formulation

  • Input: \( n = 4 \) (Example)
  • Vector: \( x[1...n] = \langle x_1, x_2, x_3, x_4 \rangle \)
  • Meaning: \( x_i \) is the column position of the queen in row \( i \).
  • Constraint: \( 1 \le x_i \le n \)

4. Sum of Subsets

Given \( n \) distinct positive numbers (weights) and a target sum \( M \), find all subsets that sum exactly to \( M \).

Example

\( n=5, \quad M=50 \)

\( A = \langle 10, 20, 30, 40, 50 \rangle \)

Solutions:
1. \( \{20, 30\} \) → \( 20+30=50 \)
2. \( \{10, 40\} \) → \( 10+40=50 \)
3. \( \{50\} \) → \( 50=50 \)

Tree Formulation

Binary Tree approach: Each node represents the decision to include (1) or exclude (0) an item.

Total Nodes in worst case: \( 2^{n+1} - 1 \)

5. Graph Coloring

Paint the graph such that no two adjacent vertices share the same color.

  • m: Number of available colors.
  • Chromatic Number: The smallest \( m \) needed to color the graph.
  • Output: Vector \( \langle x_1, x_2, \dots, x_n \rangle \) where \( x_i \) is the color of vertex \( i \).

6. Branch & Bound (B&B)

Unlike Backtracking which explores depth-first, Branch & Bound typically explores breadth-first or based on a cost function.

Branch & Bound = BFS + Bounding Functions

Queue Strategies

  • FIFO B&B: Uses a standard Queue (First In, First Out).
  • LIFO B&B: Uses a Stack (behaves like Backtracking).
  • LC (Least Cost) B&B: Uses a Priority Queue to expand the most promising node first.
