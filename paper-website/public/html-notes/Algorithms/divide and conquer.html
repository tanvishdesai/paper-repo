Divide & Conquer Strategy

Design strategies for breaking complex problems into smaller, solvable sub-problems.

1. Control Abstraction

The Divide and Conquer (D&C) paradigm involves three main steps:

1. Divide

Break the original problem into smaller sub-problems. These sub-problems should represent a part of the original problem.

2. Conquer

Solve the sub-problems recursively. If the sub-problem is small enough (base case), solve it directly.

3. Combine

Combine the solutions of the sub-problems to create the solution for the original problem. (Optional step depending on problem).

graph TD P[Problem P Size n] -->|Divide| S1[Sub P1 Size n/b] P -->|Divide| S2[Sub P2 Size n/b] P -->|Divide| Sk[Sub Pk Size n/b] S1 -->|Conquer| Sol1[Solution 1] S2 -->|Conquer| Sol2[Solution 2] Sk -->|Conquer| Solk[Solution k] Sol1 -->|Combine| F[Final Solution] Sol2 --> F Solk --> F
General Recurrence Relation: $$ T(n) = a \cdot T\left(\frac{n}{b}\right) + f(n) $$ Where:
  • \(a\): Number of sub-problems (\(a \ge 1\))
  • \(n/b\): Size of each sub-problem (\(b > 1\))
  • \(f(n)\): Cost of dividing and combining

2. Master Theorem

Used to solve recurrence relations of the form \(T(n) = aT(n/b) + f(n)\). Compare \(f(n)\) with \(n^{\log_b a}\).

Case Condition (Comparison) Result \(T(n)\)
1 \(f(n) = O(n^{\log_b a - \epsilon})\)
(Tree leaves dominate cost)		 $$ \Theta(n^{\log_b a}) $$
2 \(f(n) = \Theta(n^{\log_b a} \log^k n)\)
(Work is evenly distributed)		 $$ \Theta(n^{\log_b a} \log^{k+1} n) $$
3 \(f(n) = \Omega(n^{\log_b a + \epsilon})\)
(Root dominates cost)
*Regularity condition: \(a f(n/b) \le \delta f(n)\)		 $$ \Theta(f(n)) $$

Example

Given \(T(n) = 2T(n/2) + n\). Find Complexity.

  • \(a=2, b=2\). Calculate \(n^{\log_b a} = n^{\log_2 2} = n^1\).
  • \(f(n) = n\).
  • Comparison: \(f(n)\) is equal to \(n^{\log_b a}\). This is Case 2 with \(k=0\).
  • Result: \(T(n) = \Theta(n^1 \log^{0+1} n) = \Theta(n \log n)\).

3. Max-Min Problem

Goal: Find the Maximum and Minimum elements in an array of size \(n\).

Straightforward Approach

Compare every element against current max and min.

Comparisons: \(2(n-1)\) (Worst Case)

Complexity: \(O(n)\)

Divide & Conquer Approach

Split list into halves. Recursively find (min, max) in left and right. Compare 2 pairs.

Recurrence: \(T(n) = 2T(n/2) + 2\)

Comparisons: \(\lceil \frac{3n}{2} \rceil - 2\)

Improvement

The D&C method reduces the number of comparisons by approx 25% compared to the naive method, though asymptotic complexity remains \(O(n)\).

4. Binary Search

Pre-condition: The list must be sorted.

Algorithm Logic

mid = (low + high) / 2
if (x == A[mid]) return mid
else if (x < A[mid]) high = mid - 1
else low = mid + 1

Analysis

  • Recurrence: \(T(n) = T(n/2) + 1\)
  • Master Thm: \(a=1, b=2 \implies n^0 = 1\).
    \(f(n) = 1 (\text{constant})\).
    Case 2 holds.
  • Time: \(O(\log n)\)
  • Space: \(O(1)\) (Iterative), \(O(\log n)\) (Recursive stack)

5. Merge Sort

A classic D&C algorithm that guarantees \(O(n \log n)\) time complexity. It works by splitting the array into individual elements and merging them back in sorted order.

graph TD A[38, 27, 43, 3] --> B[38, 27] A --> C[43, 3] B --> D[38] B --> E[27] C --> F[43] C --> G[3] D --> H[27, 38] E --> H F --> I[3, 43] G --> I H --> J[3, 27, 38, 43] I --> J style J fill:#dcfce7,stroke:#166534

Recurrence Relation

$$ T(n) = 2T\left(\frac{n}{2}\right) + n $$
  • \(2T(n/2)\): Recursive calls on halves.
  • \(n\): Time to merge two sorted arrays of size \(n/2\).

Complexity

  • Time: \(\Theta(n \log n)\) in Best, Average, and Worst cases.
  • Space: \(O(n)\) (Out-of-place sorting, requires auxiliary array).

6. Quick Sort

Uses a Partition algorithm. It picks a "Pivot" element and rearranges the array so that elements smaller than pivot are on the left, and larger on the right.

Partition Logic (Lomuto or Hoare): Iterate pointers from Left and Right. Swap elements to ensure Pivot ends up in its correct sorted position.
Complexity of Partition: \(O(n)\).
Scenario Tree Structure Recurrence Complexity
Best Case
Pivot is Median		 Balanced Tree \(T(n) = 2T(n/2) + n\) \(O(n \log n)\)
Worst Case
Sorted/Reverse Sorted		 Skewed Tree (Line) \(T(n) = T(n-1) + n\) \(O(n^2)\)
Space Complexity: Quick Sort is an in-place sort (doesn't need \(O(n)\) aux array like Merge Sort), but it uses Stack Space.
Best: \(O(\log n)\) stack. Worst: \(O(n)\) stack.

7. Advanced Applications

Matrix Multiplication (Strassen's Algorithm)

Multiplying two \(n \times n\) matrices.

  • Naive D&C: Performs 8 multiplications of size \(n/2\).
    \(T(n) = 8T(n/2) + n^2 \implies O(n^3)\).
  • Strassen's: Uses algebraic tricks to reduce multiplications to 7.
    \(T(n) = 7T(n/2) + n^2 \implies O(n^{\log_2 7}) \approx O(n^{2.81})\).

Long Integer Multiplication (Karatsuba)

Multiplying two \(n\)-digit numbers.

  • Naive: \(O(n^2)\).
  • Karatsuba: Splits numbers and performs 3 multiplications instead of 4.
    \(T(n) = 3T(n/2) + cn \implies O(n^{\log_2 3}) \approx O(n^{1.58})\).
