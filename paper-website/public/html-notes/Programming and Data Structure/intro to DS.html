3. Operators

Precedence & Associativity

Decides the order of evaluation when multiple operators are present.

Priority Operators Associativity
1 (Highest) ( ), [ ], -> Left to Right
2 (Unary) ++, --, !, &, *, sizeof Right to Left
3 (Arithmetic) *, /, % Left to Right
4 (Arithmetic) +, - Left to Right
5 (Relational) <, <=, >, >= Left to Right
6 (Equality) ==, != Left to Right
... ... ...
(Lowest) = (Assignment) Right to Left

Integer vs Float Division

int a = 5/2;   // Result: 2 (Integer division truncates)
float b = 5.0/2; // Result: 2.5 (One operand is float)
// Note: Modulo (%) only works with integers!

Logical Short-Circuiting

  • AND (&&): If the first operand is False (0), the second is not evaluated. Result is 0.
  • OR (||): If the first operand is True (non-zero), the second is not evaluated. Result is 1.
int a = 10;
int b = 0 && (++a); 
// a remains 10 because lhs was 0, rhs (++a) was skipped.

4. Functions

Architecture of a Function Call

When a function is called, an Activation Record (Stack Frame) is created in the Stack memory.

graph BT subgraph Stack Memory direction BT MainFrame[Main Function Frame
a=10, b=20] FuncFrame[Add Function Frame
x=10, y=20, sum=30] end MainFrame -- Calls Add(a,b) --> FuncFrame FuncFrame -- Returns 30 --> MainFrame

Note: Variables inside a function (local) are destroyed when the function returns.

Forward Declaration

If you define a function after `main()`, you must declare it before `main()`. Otherwise, the compiler assumes the return type is `int` by default, which may cause errors if the function returns `float`.

5. Arrays

A collection of elements of the same type stored in contiguous memory locations.

int a[4] = {10, 20, 30, 40};

Address of next element = Base Address + (Index × Size of Data Type).

Key Properties

  • Random Access: Any element can be accessed directly using the index.
  • Array Name: The name `a` acts as a constant pointer to the first element (base address).
  • Bounds: C does not check array boundaries. Accessing `a[5]` in an array of size 4 leads to Undefined Behavior (Garbage value).

6. Pointers & Arithmetic

The Basics

A pointer is a variable that stores the memory address of another variable.

int a = 10;
int *p = &a;  // p holds the address of a
graph LR subgraph Pointer P P_Val[Value: 2036] end subgraph Variable A A_Addr[Address: 2036] A_Val[Value: 10] end P_Val --> A_Addr

Pointer Arithmetic

If `p` points to integer (4 bytes) at address 1000:

  • p + 1 results in 1004 (moves 1 integer forward).
  • *(p + 1) accesses the value at that new address.
The "Mentos" Trick (Array/Pointer Equivalence):
The compiler converts array syntax to pointer arithmetic internally. $$ a[i] \iff *(a + i) \iff *(i + a) \iff i[a] $$ Yes, 2[a] is valid C syntax and means the same as a[2]!

2D Arrays & Pointers

int a[2][3]; (2 rows, 3 columns)

Row Major Order (stored linearly in memory):

Row 0
0,0
0,1
0,2
Row 1
1,0
1,1
1,2
  • a: Pointer to the first row (whole 1D array of 3 ints).
  • a[0]: Pointer to the first integer of first row.
  • *(*(a + i) + j): Value at a[i][j].

7. Advanced Pointer Concepts

Call by Value vs Call by Reference

Code Comparison

Call by Value

void swap(int x, int y) {
    int temp = x;
    x = y; 
    y = temp;
}
// No change in main() variables.
// Only copies were swapped.

Call by Reference

void swap(int *x, int *y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}
// call: swap(&a, &b);
// Changes affect main() variables.

Pointer to Array vs Array of Pointers

Declaration Meaning
int *p[4]; Array of Pointers: An array size 4, where each element is a pointer to an int. (Precedence: `[]` > `*`).
int (*p)[4]; Pointer to Array: A single pointer variable `p` that points to a complete array of 4 integers.

Incrementing Pointers

Assuming int a[4]; and ptr points to it:

  • ptr + 1: Address increases by 4 bytes (next integer).
  • &a + 1: Address increases by 16 bytes (skips the whole array).
