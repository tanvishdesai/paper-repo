Digital Logic: Number Systems

Complete cheat sheet for CS & IT Engineering covering Bases, Conversions, Signed Arithmetic, and Complements.

1. Number System Fundamentals

Base (Radix) \(r\)

Total number of unique digits used in the system.

  • Binary: Base 2 \(\{0, 1\}\)
  • Octal: Base 8 \(\{0, \dots, 7\}\)
  • Decimal: Base 10 \(\{0, \dots, 9\}\)
  • Hexadecimal: Base 16 \(\{0, \dots, 9, A, B, C, D, E, F\}\)

Positional Weight

Value of a digit depends on its position.

$$ N = \sum_{i=-m}^{n} a_i \times r^i $$

Example: \((101.11)_2 = 1\cdot2^2 + 0\cdot2^1 + 1\cdot2^0 + 1\cdot2^{-1} + 1\cdot2^{-2}\)

4. Magnitude Representation

How computers store negative numbers.

Signed Magnitude

  • MSB: 0 = Positive (+), 1 = Negative (-).
  • Remaining bits: Magnitude.
  • Problem Two zeros (+0, -0). Calculations are complex.

2's Complement (Standard)

  • Positive: Same as Unsigned.
  • Negative: Invert all bits (1's Comp) and add 1.
  • Benefit Unique zero. Efficient arithmetic.

5. Complements & Arithmetic

Used to perform subtraction using addition logic.

Types of Complements

(r-1)'s Complement

Subtract each digit from \((r-1)\).

  • Binary (1's): Flip bits (0→1, 1→0).
  • Decimal (9's): Subtract digit from 9.

r's Complement

Formula: \((r-1)\text{'s Complement} + 1\)

  • Binary (2's): 1's Comp + 1.
  • Decimal (10's): 9's Comp + 1.

Subtraction using 2's Complement

$$ X - Y \Rightarrow X + (2\text{'s Comp of } Y) $$
Example: 10 - 26 (using 6-bit registers)
  1. Represent 10: 001010
  2. Represent 26: 011010
  3. Find 2's Comp of 26:
    • 1's: 100101
    • Add 1: 100110 (-26)
  4. Add (10) + (-26): 
      001010
+ 100110
--------
  110000
  5. Result is 110000. Since MSB is 1, it's negative.
  6. Magnitude: 2's comp of 110000 is 010000 (16).
  7. Answer: -16

7. Solving Base Equations

When finding unknown base \(r\) or digits \(x, y\).

Constraint Check

Rule: The base \(r\) must be strictly greater than any digit in the number.

Example: In \((41)_x = 5\), digit 4 exists, so \(x > 4\).

Equation Expansion

Convert both sides to Decimal to solve for \(r\).

\(\sqrt{(41)_x} = 5 \implies (41)_x = 25_{10}\)
\(4x^1 + 1x^0 = 25 \implies 4x + 1 = 25 \implies 4x = 24 \implies x = 6\)

Common Tricks

  • If \(A + B = C\) creates a carry, check if sum exceeds base.
  • For \((123)_5 = (x8)_y\), first convert LHS to decimal, then convert decimal to base \(y\) (knowing \(y > 8\)).
