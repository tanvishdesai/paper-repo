Sequential vs. Combinational

Combinational Circuit
Output depends only on present inputs.
No Memory. No Feedback.
Ex: Adder, Mux, Decoder.
Sequential Circuit
Output depends on present inputs AND past outputs.
Has Memory & Feedback.
Ex: Flip-Flop, Counter, Register.

3. The Race Around Condition

The Problem

Occurs in Level Triggered JK Flip-Flops when \(J=K=1\) (Toggle Mode).

If the Clock Pulse Width (\(T_{pw}\)) is greater than the propagation delay (\(t_{pd}\)), the output toggles multiple times within a single clock pulse.

Condition causing Race: \(T_{pw} > t_{pd}\)

The Solution

  1. Edge Triggering: Reduces the sensitive time to an instant.
  2. Master-Slave Flip-Flop:
    • Two FFs cascaded (Master = Level, Slave = Level inverted).
    • Master samples input on High Clock.
    • Slave updates output on Low Clock.
    • Output changes only once per cycle.

5. Asynchronous (Ripple) Counters

Asynchronous

The external clock is applied only to the first Flip-Flop (LSB). The output of one FF acts as the clock for the next.

Configuration

  • Up Counter: Connect \(\bar{Q}\) to next CLK (for -ve edge T-FF).
  • Down Counter: Connect \(Q\) to next CLK (for -ve edge T-FF).

Timing Constraints

Slow due to accumulated propagation delay.

$$T_{clk} \ge N \times t_{pd}$$

$$f_{max} = \frac{1}{N \times t_{pd}}$$

Modulo (MOD) Counters

To create a MOD-\(X\) counter (where \(X < 2^n\)):

  1. Find number of FFs: \(2^n \ge X\).
  2. Design a standard ripple counter.
  3. Use a Clear (CLR) or Reset logic. When the counter reaches state \(X\), triggers a reset to 0.
  4. Example: MOD-10 (BCD) counts 0-9. On state 10 (1010), NAND gate triggers CLR.

6. Synchronous Counters

Synchronous

All Flip-Flops receive the same clock pulse simultaneously. Faster, but more complex hardware.

Design Steps

  1. Determine number of Flip-Flops needed.
  2. Draw the State Diagram (e.g., \(0 \to 1 \to 2 \to 0\)).
  3. Create the Excitation Table (Present State, Next State, Required Inputs).
  4. Solve K-Maps for Flip-Flop inputs (e.g., \(J_A, K_A, J_B, K_B\)).
  5. Draw the circuit diagram.

Delay Formulas

Counter Type Max Frequency Formula
Ripple (Async) \(f \le \frac{1}{n \times t_{pd}}\)
Synchronous \(f \le \frac{1}{t_{pd(FF)} + t_{pd(Gate)}}\)

7. Special Shift Register Counters

Synchronous counters built using Shift Registers with feedback.

Ring Counter

graph LR FF1 --> FF2 --> FF3 --> FF4 FF4 -->|Feedback Q| FF1
  • Feedback: Output \(Q\) of last stage to Input of first.
  • MOD Number: \(N\) (where N is number of FFs).
  • States: Used: \(N\), Unused: \(2^N - N\).
  • Self-Starting? No. Needs manual preset (e.g., 1000).
  • Sequence: 1000 \(\to\) 0100 \(\to\) 0010 \(\to\) 0001.

Johnson Counter (Twisted Ring)

graph LR FF1 --> FF2 --> FF3 --> FF4 FF4 -->|Feedback Q'| FF1
  • Feedback: Output \(\bar{Q}\) of last stage to Input of first.
  • MOD Number: \(2N\).
  • States: Used: \(2N\), Unused: \(2^N - 2N\).
  • Self-Starting? Yes (usually recovers).
  • Sequence: 0000 \(\to\) 1000 \(\to\) 1100 \(\to\) 1110 \(\to\) 1111 \(\to\) 0111...
  • Known as "Walking Counter" or "Moebius Counter".
