1. Fundamentals & Memory

Basic Units

  • Bit (b): 0 or 1.
  • Byte (B): Group of 8 bits.
  • Word: Number of bits processed simultaneously (e.g., 32-bit or 64-bit).

Byte Ordering (Endianness)

How multi-byte data is stored in memory.

Addressability

Total Memory Capacity Formula:

$$ \text{Capacity} = 2^{\text{Address Bits}} \times \text{Addressable Unit Size} $$
Type Description Example (16-bit Address)
Byte Addressable Each address points to 1 Byte (8 bits). Capacity = \(2^{16}\) Bytes = 64 KB
Word Addressable Each address points to 1 Word (e.g., 16 or 32 bits). Capacity = \(2^{16}\) Words = 64 KWords

An instruction tells the processor what to do. It consists of groups of bits called fields.

3. ISA Classifications

Architectures are classified by the number of operands explicitly specified in the instruction.

0-Address Stack CPU

Concept: Operands are implicitly on the Top of Stack (TOS).

Instructions: PUSH A, POP X, ADD.

Expression: Reverse Polish Notation (Postfix).

ADD implies \( TOS \leftarrow TOS + TOS_{prev} \)

1-Address Accumulator

Concept: One operand is always the Accumulator (AC).

Instructions: LOAD A, STORE B, ADD X.

Logic: \( AC \leftarrow AC + M[X] \)

2/3-Address GPR

Concept: General Purpose Registers. Used in modern RISC/CISC.

2-Addr: ADD R1, R2 implies \( R1 \leftarrow R1 + R2 \)

3-Addr: ADD R1, R2, R3 implies \( R1 \leftarrow R2 + R3 \)

Example: Evaluate X = (A + B) * (C + D)

4. Expanding Opcode Technique

A technique to increase the instruction set size by trading address bits for opcode bits in fixed-length instructions.

The Golden Rule

$$ \text{Total Ops} = \text{Fixed Ops} + (\text{Free Patterns} \times 2^{\text{Size of Freed Field}}) $$

Algorithm to find Derived Instructions

  1. Step 1: Calculate Max Operations possible for the largest instruction format (Primitive).
  2. Step 2: Subtract the number of existing primitive instructions.
  3. Step 3: Multiply the remainder by \(2^k\) (where \(k\) is the number of bits in the field being freed).
Example Calculation

Scenario: 16-bit instruction. Address field = 4 bits.

Suppose we have 15 3-Address instructions (Primitive). How many 2-Address instructions are possible?

Format: Opcode (4 bits) | R1 (4) | R2 (4) | R3 (4)

Total Patterns with 4-bit opcode = \(2^4 = 16\).

Used = 15.

Free Patterns = \(16 - 15 = 1\).

When moving from 3-Addr to 2-Addr, we free up one 4-bit field.

2-Address Ops = \( 1 \times 2^4 = 16 \).

How the processor calculates the Effective Address (EA) of the operand.

PC Relative Addressing

Used for Relocatable Code and Branching.

$$ EA = PC_{next} + \text{Offset} $$

Note

PC usually points to the next instruction during execution.

Base Register Addressing

Used for Program Relocation in memory.

$$ EA = \text{Base Register} + \text{Offset} $$

Allows moving entire program segments by changing just the Base Register.

Relative Branching Calculation

When calculating the target address for a branch:

$$ \text{Target Addr} = \text{Current PC} + \text{Offset} $$
  • Forward Jump: Positive Offset.
  • Backward Jump: Negative Offset.
