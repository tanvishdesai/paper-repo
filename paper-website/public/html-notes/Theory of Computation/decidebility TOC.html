Decidability & Computation

A comprehensive reference for Decidable languages, Undecidable problems, Reducibility, and Context Free Grammar simplifications.

1. Decidability Classifications

Fundamental

● Decidable (D)

Also known as Recursive Language.

Yes Case Logic Exists ✓
No Case Logic Exists ✓
  • Machine: Halting Turing Machine (HTM) exists.
  • Behavior: Always halts (Accepts or Rejects).
  • Example: Finite Automata Membership.

● SDUD

Semi-Decidable Undecidable (REL but not Recursive).

Yes Case Logic Exists ✓
No Case No Logic ✗
  • Machine: Standard TM exists, but no HTM.
  • Behavior: May loop forever on "No" inputs.
  • Example: Halting Problem ($A_{TM}$).

● NR (Not REL)

Not Recursively Enumerable.

Yes Case No Logic ✗
No Case No Logic ✗
  • Machine: No Turing Machine exists.
  • Behavior: Completely unrecognizable.
  • Example: Complement of Halting Problem ($\overline{HP}$).

3. Reducibility ($A \le B$)

Logic Tool

The Concept

If Problem A reduces to Problem B ($A \le B$), then B is at least as hard as A.

Analogy: Delhi $\le$ India. If you can conquer India, you have automatically conquered Delhi.

1. If $A \le B$ and B is Decidable → A is Decidable.

2. If $A \le B$ and A is Undecidable → B is Undecidable.

CNF (Chomsky Normal Form)

Every production is of the form:

A → BC
A → a
  • Restricted to exactly 2 variables or 1 terminal.
  • Derivation Steps: To generate a string of length $|w| = n$:
  • Steps = $2n - 1$

GNF (Greibach Normal Form)

Every production is of the form:

A → aα
(α is string of variables)
  • Starts with a terminal, followed by any number of variables.
  • Used for PDA construction (Pushdown Automata).
  • Derivation Steps: To generate a string of length $|w| = n$:
  • Steps = $n$

5. Rice's Theorem & Hierarchy

Rice's Theorem

"Any non-trivial property of the language recognized by a Turing Machine (RE Language) is Undecidable."

Property ($P$): A subset of REL languages.

Trivial: $P = \emptyset$ (None) or $P = \text{All REL}$.

Example: "Does $L(M)$ contain the string '101'?" is non-trivial, thus Undecidable.

Countability

  • Countable Sets: Finite sets, Natural Numbers ($\mathbb{N}$), Integers ($\mathbb{Z}$), $\Sigma^*$, Set of all TMs, Set of all C Programs.
  • Uncountable Sets: Real Numbers ($\mathbb{R}$), Power Set of Sigma Star ($2^{\Sigma^*}$), Set of all Languages.

Conclusion: There are more Languages than Turing Machines. Therefore, some languages are not recognized by any machine (Not REL).
