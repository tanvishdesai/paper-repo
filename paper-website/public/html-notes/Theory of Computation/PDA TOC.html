1. Chomsky Hierarchy & Concepts

Language Hierarchy

The relationship between language classes is strictly hierarchical:

graph TD subgraph All Languages subgraph "Context Sensitive (CSL)" subgraph "Context Free (CFL)" subgraph "Deterministic CFL (DCFL)" subgraph "Regular Languages" RL[Finite Automata] end DCFL[DPDA] end CFL[PDA / NPDA] end CSL[Linear Bounded Automata] end end RL --> DCFL DCFL --> CFL CFL --> CSL
  • Regular: Can be recognized by Finite Automata (DFA/NFA) with \(O(1)\) memory.
  • DCFL: Recognized by Deterministic PDA. No ambiguity allowed.
  • CFL: Recognized by Non-deterministic PDA. Can handle ambiguity. Uses a Stack.
  • Not CFL: Requires 2 or more stacks, or context-dependent checks (e.g., \(a^nb^nc^n\)).

2. Context Free Grammars (CFG)

A CFG is defined as a 4-tuple \(G = (V, T, P, S)\):

  • \(V\): Set of Variables (Non-terminals)
  • \(T\): Set of Terminals
  • \(P\): Production Rules of form \(A \to \alpha\), where \(A \in V\) and \(\alpha \in (V \cup T)^*\)
  • \(S\): Start Symbol
graph LR A[Source Code] --> B[Lexical Analysis] B -->|Tokens| C[Syntax Analysis] C -->|Parse Tree| D[Semantic Analysis] style C fill:#f9f,stroke:#333,stroke-width:2px

Note: CFGs define the Syntax (structure) of programming languages.

Derivations & Ambiguity

Left Most Derivation (LMD): Always replace the leftmost non-terminal.

Right Most Derivation (RMD): Always replace the rightmost non-terminal.

Ambiguity: A grammar is ambiguous if a string \(w\) has:

  • More than 1 Parse Tree
  • More than 1 LMD
  • More than 1 RMD

Inherently Ambiguous Language: If all grammars generating language \(L\) are ambiguous.

3. Push Down Automata (PDA)

$$PDA \cong \text{Finite Automata} + 1 \text{ Stack}$$

Formal Definition (7-tuple): \(M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)\)

  • \(\Gamma\): Stack Alphabet
  • \(Z_0\): Initial Stack Symbol
  • \(\delta\): Transition Function \(\delta: Q \times (\Sigma \cup \{\epsilon\}) \times \Gamma \to P(Q \times \Gamma^*)\)

Stack Operations Logic

stateDiagram-v2 [*] --> q0 q0 --> q0: a, Z0 / aZ0 (PUSH) q0 --> q1: b, a / ε (POP) q1 --> q1: b, a / ε (POP) q1 --> q2: ε, Z0 / Z0 (SKIP/Accept)

Notation: Input, TopOfStack / PushToStack

  • a, Z0 / aZ0: Read 'a', if Top is 'Z0', Push 'a'. (Stack becomes aZ0)
  • b, a / ε: Read 'b', if Top is 'a', Pop 'a'.
  • ε, Z0 / Z0: Without reading input (epsilon move), check if Top is Z0, keep it (Skip).

4. Deterministic vs Non-Deterministic PDA

Feature DPDA (Deterministic) NPDA (Non-Deterministic)
Determinism At most 1 move possible for any configuration. Multiple moves allowed.
Transition Constraints If \(\delta(q, a, X)\) exists, then \(\delta(q, \epsilon, X)\) must NOT exist. No constraints.
Power Accepts DCFL (subset of CFL). Accepts all CFL.
Acceptance Accepted by Final State \(\neq\) Empty Stack. Final State \(\cong\) Empty Stack.
Prefix Property To accept by Empty Stack, \(L\) must have prefix property. N/A

Prefix Property: A language \(L\) has the prefix property if no string in \(L\) is a proper prefix of another string in \(L\).
Example: \(L = \{a, aa\}\) does NOT satisfy prefix property. DPDA via Empty Stack cannot accept it.

5. Common Languages Map

A quick reference to classify common patterns.

Regular Languages

Regular

  • \(a^n b^m\) (No dependency between n and m)
  • \(w w^R\) where \(|w| < 100\) (Finite languages)
  • \(a^* b^*\)

Deterministic Context Free (DCFL)

DCFL but not Regular

  • \(L = \{ a^n b^n \mid n \ge 1 \}\) (Stack pushes 'a's, pops on 'b's)
  • \(L = \{ a^n b^{2n} \mid n \ge 1 \}\) (Push 2 'a's or Pop 1 for 2)
  • \(L = \{ w c w^R \mid w \in \{a,b\}^* \}\) (The 'c' acts as a clear midpoint marker)
  • \(L = \{ a^n b^m \mid n \neq m \}\) (Requires determinism to check equality then reject/accept)
  • \(L = \{ a^n b^n c^m \cup a^n b^m c^m \}\) is NOT DCFL (Ambiguity in structure).

Context Free (CFL)

CFL but not DCFL

  • \(L = \{ w w^R \mid w \in \{a,b\}^* \}\) (Even palindromes without marker. Non-determinism needed to guess midpoint)
  • \(L = \{ a^n b^n \} \cup \{ a^n b^{2n} \}\) (Union of DCFLs is not always DCFL)
  • \(L = \{ a^n b^k c^k \mid n,k \ge 0 \} \cup \{ a^n b^n c^k \mid n,k \ge 0 \}\) (Commonly cited inherently ambiguous language)

Not Context Free

Not CFL (Requires Context Sensitive / Turing)

  • \(L = \{ a^n b^n c^n \}\) (Requires comparing 3 groups; stack can only compare 2)
  • \(L = \{ w w \mid w \in \{a,b\}^* \}\) (Copy language)
  • \(L = \{ a^p \mid p \text{ is prime} \}\)
  • \(L = \{ a^{n^2} \}\)
  • \(L = \{ a^n b^n c^n d^n \}\)

6. Closure Properties

Memorization Key: Regular languages are the most closed. DCFLs are picky. CFLs hate Intersection and Complement.

Operation Regular DCFL CFL
Union ✅ Yes ❌ No ✅ Yes
Intersection ✅ Yes ❌ No ❌ No
Complement ✅ Yes ✅ Yes ❌ No
Concatenation ✅ Yes ❌ No ✅ Yes
Kleene Star ✅ Yes ❌ No ✅ Yes
Intersection w/ Regular ✅ Yes ✅ Yes ✅ Yes
Reversal ✅ Yes ❌ No ✅ Yes
Prefix / Suffix ✅ Yes ✅ Yes ✅ Yes

Important Logic: \( \text{CFL} \cap \text{CFL} \) is NOT necessarily CFL (e.g., \(a^nb^nc^m \cap a^mb^nc^n = a^nb^nc^n\)).

8. Algorithms & Simplification

Simplifying CFGs

  1. Eliminate \(\epsilon\)-productions: Remove \(A \to \epsilon\).
  2. Eliminate Unit Productions: Remove \(A \to B\).
  3. Eliminate Useless Symbols: Remove non-reachable or non-generating symbols.

Normal Forms

  • CNF (Chomsky Normal Form): Rules are \(A \to BC\) or \(A \to a\). Parse tree is a binary tree. Height is \(O(\log |w|)\).
  • GNF (Greibach Normal Form): Rules are \(A \to a\alpha\) where \(a\) is terminal and \(\alpha\) is non-terminal string. Useful for converting CFG to PDA.

CYK Algorithm

Used to check membership for CFLs. Requires grammar in CNF. Time Complexity: \(O(n^3)\) where \(n = |w|\).
