Probability & Statistics: The Core

A comprehensive summary of Random Variables, Distributions, and Statistical Averages for GATE Engineering Mathematics.

1. Fundamentals

Basic Definitions

  • Random Experiment ($\Omega$): Process with uncertain outcomes (e.g., Tossing a coin).
  • Sample Space ($S$): Set of all possible outcomes.
  • Event ($E$): Subset of Sample Space.
$$P(E) = \frac{\text{No. of Favorable Outcomes } n(E)}{\text{Total Outcomes } n(S)}$$

Axioms

  • $0 \leq P(E) \leq 1$
  • $P(S) = 1$ (Total Probability)
  • $P(A \cup B) = P(A) + P(B) - P(A \cap B)$
  • For mutually exclusive events: $P(A \cap B) = 0$

2. Conditional Probability & Bayes' Theorem

Conditional Probability

The probability of event A occurring given that event B has already occurred.

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

Independence: Two events are independent if $P(A \cap B) = P(A) \cdot P(B)$. In this case, $P(A|B) = P(A)$.

Bayes' Theorem (Reverse Probability)

Used when finding the probability of a "cause" given an "effect". Often visualized using Tree Diagrams.

4. Statistical Averages

Mean / Expectation ($\mu$ or $E[X]$)

The center of gravity/mass of the distribution.

  • Discrete: $\sum x_i \cdot P(x_i)$
  • Continuous: $\int_{-\infty}^{\infty} x \cdot f(x) dx$
Properties of E[X]
  • $E[k] = k$
  • $E[aX + b] = aE[X] + b$
  • $E[X + Y] = E[X] + E[Y]$
  • If Indep: $E[XY] = E[X]E[Y]$

Variance ($\sigma^2$ or $V(X)$)

Measure of spread/dispersion around the mean.

$$V(X) = E[X^2] - (E[X])^2$$

Standard Deviation: $\sigma = \sqrt{V(X)}$

Properties of V(X)
  • $V(c) = 0$
  • $V(aX + b) = a^2 V(X)$
  • $V(-X) = V(X)$
  • If Indep: $V(X \pm Y) = V(X) + V(Y)$

5. Discrete Distributions

Bernoulli Distribution

Single trial with two outcomes: Success ($p$) or Failure ($q=1-p$).

Binomial Distribution ($n, p$)

Number of successes in $n$ independent Bernoulli trials.

$$P(X=r) = \binom{n}{r} p^r q^{n-r}$$
  • Mean: $np$
  • Variance: $npq$
  • Mode: $(n+1)p$ (Check integer vs non-integer)

Poisson Distribution ($\lambda$)

Modeling rare events over a fixed interval (Time/Space). Limiting case of Binomial where $n \to \infty, p \to 0$.

$$P(X=k) = \frac{e^{-\lambda} \lambda^k}{k!}$$
  • Parameter: $\lambda$ (Average rate)
  • Mean: $\lambda$
  • Variance: $\lambda$
  • Only distribution where Mean = Variance.

6. Continuous Distributions

Uniform Distribution $U[a, b]$

Constant probability density over an interval.

PDF: $f(x) = \frac{1}{b-a}$ for $a \le x \le b$

Mean: $\frac{a+b}{2}$

Variance: $\frac{(b-a)^2}{12}$

Exponential Distribution

Time between events in a Poisson process. (Memoryless property).

$$f(x) = \lambda e^{-\lambda x}, \quad x \ge 0$$
  • Mean: $1/\lambda$
  • Variance: $1/\lambda^2$
  • CDF: $P(X \le x) = 1 - e^{-\lambda x}$

Normal (Gaussian) Distribution $N(\mu, \sigma^2)$

Bell-shaped curve. Symmetric about the mean.

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}$$

7. Calculus Tricks for Probability

Useful for solving Continuous Random Variable problems.

Integration Shortcuts

$$\int_{0}^{\infty} e^{-ax} dx = \frac{1}{a}$$

Gamma Function

Useful for integrals of form $\int_{0}^{\infty} x^n e^{-x} dx$.

$$\Gamma(n) = (n-1)! \quad \text{(for integer n)}$$ $$\Gamma(1/2) = \sqrt{\pi}$$

Compound Functions

If dealing with $|x|$, split the integral:

$$\int_{-\infty}^{\infty} f(|x|) dx = \int_{-\infty}^{0} f(-x) dx + \int_{0}^{\infty} f(x) dx$$

If $f(x)$ is even, $= 2 \int_{0}^{\infty} f(x) dx$.
