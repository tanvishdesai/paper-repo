Fourier Series

Engineering Mathematics • One Shot Summary

Based on Lecture by Rahul Sir (2024)

TheoryWhy Fourier Series?

Taylor Series

Applies only to differentiable functions.

Fails at corners or discontinuities.

Fourier Series

Applies to periodic functions.

Handles discontinuities, corners, and non-differentiable points (e.g., Square wave, Sawtooth).

graph LR A[Function f x] --> B{Is it Periodic?} B -- Yes --> C[Use Fourier Series] B -- No --> D{Is it Differentiable?} D -- Yes --> E[Use Taylor/Maclaurin] D -- No --> F[Advanced Techniques]

MathThe Master Formula

For a periodic function $f(x)$ with period $T = 2\pi$ defined in interval $(0, 2\pi)$ or $(-\pi, \pi)$:

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos(nx) + \sum_{n=1}^{\infty} b_n \sin(nx)$$

Euler's Formulas for Coefficients

Choose the limits based on your problem statement.

Coefficient Interval $[0, 2\pi]$ Interval $[-\pi, \pi]$
$a_0$ (DC Term) $$\frac{1}{\pi} \int_{0}^{2\pi} f(x) dx$$ $$\frac{1}{\pi} \int_{-\pi}^{\pi} f(x) dx$$
$a_n$ (Cosine) $$\frac{1}{\pi} \int_{0}^{2\pi} f(x) \cos(nx) dx$$ $$\frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \cos(nx) dx$$
$b_n$ (Sine) $$\frac{1}{\pi} \int_{0}^{2\pi} f(x) \sin(nx) dx$$ $$\frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \sin(nx) dx$$

ShortcutSymmetry (Even vs Odd)

Crucial for Interval $(-\pi, \pi)$. Checking symmetry can save you 50% of the integration work.

flowchart TD Start[Check f -x] Start --> Even{Is f -x = f x ?} Start --> Odd{Is f -x = -f x ?} Even -- Yes --> Res1[Even Function] Res1 --> C1[b_n = 0] Res1 --> C2[Find a_0 and a_n] Odd -- Yes --> Res2[Odd Function] Res2 --> C3[a_0 = 0] Res2 --> C4[a_n = 0] Res2 --> C5[Find ONLY b_n]
  • Even Function (Cos-like): Symmetric about Y-axis (e.g., $x^2, \cos x$). Result contains only Cosine terms.
  • Odd Function (Sin-like): Symmetric about Origin (e.g., $x, x^3, \sin x$). Result contains only Sine terms.

Example 1: Sawtooth Wave

Problem: Find Fourier series for $f(x) = x$ in interval $0 < x < 2\pi$.

Step 1: Calculate $a_0$
$$a_0 = \frac{1}{\pi} \int_{0}^{2\pi} x dx = \frac{1}{\pi} \left[ \frac{x^2}{2} \right]_0^{2\pi} = \frac{1}{\pi} \frac{4\pi^2}{2} = 2\pi$$
Step 2: Calculate $a_n$

Using integration by parts (Bernoulli's rule):

$$a_n = \frac{1}{\pi} \int_{0}^{2\pi} x \cos(nx) dx$$ $$= \frac{1}{\pi} \left[ x \frac{\sin(nx)}{n} - (1)\frac{-\cos(nx)}{n^2} \right]_0^{2\pi}$$

Since $\sin(2n\pi)=0$ and $\cos(2n\pi)=1$: The terms cancel out.

Result: $a_n = 0$

Step 3: Calculate $b_n$
$$b_n = \frac{1}{\pi} \int_{0}^{2\pi} x \sin(nx) dx$$ $$= \frac{1}{\pi} \left[ x \frac{-\cos(nx)}{n} - (1)\frac{-\sin(nx)}{n^2} \right]_0^{2\pi}$$

Applying limits:

  • Upper Limit ($2\pi$): $-\frac{2\pi}{n}$
  • Lower Limit ($0$): $0$

Result: $b_n = -\frac{2}{n}$

Final Solution

$$f(x) = \pi - 2 \sum_{n=1}^{\infty} \frac{\sin(nx)}{n}$$

Example 2: Discontinuous Step Function

Problem: Find Fourier series for:

$$f(x) = \begin{cases} -1 & -\pi < x < -\pi/2 \\ 0 & -\pi/2 < x < \pi/2 \\ 1 & \pi/2 < x < \pi \end{cases}$$

Logic Check

Check symmetry: $f(-x) = -f(x)$. This is an ODD Function.

Therefore: $a_0 = 0$ and $a_n = 0$. We only calculate $b_n$.

Calculate $b_n$

We integrate over the specific regions where $f(x) \neq 0$.

$$b_n = \frac{1}{\pi} \left[ \int_{-\pi}^{-\pi/2} (-1)\sin(nx)dx + \int_{\pi/2}^{\pi} (1)\sin(nx)dx \right]$$

After integrating and applying limits, we get terms involving $\cos(n\pi)$ and $\cos(n\pi/2)$.

Simplified Coefficient:

$$b_n = \frac{2}{n\pi} \left[ \cos\left(\frac{n\pi}{2}\right) - \cos(n\pi) \right]$$

Expanded Series

Substituting $n=1, 2, 3$:

  • $n=1: b_1 = \frac{2}{\pi}$
  • $n=2: b_2 = -\frac{2}{\pi}$
  • $n=3: b_3 = \frac{2}{3\pi}$
$$f(x) = \frac{2}{\pi} \sin x - \frac{2}{\pi} \sin 2x + \frac{2}{3\pi} \sin 3x + \dots$$
