IP Support Protocols

Comprehensive notes on ARP, RARP, and ICMP from Computer Networks Engineering.

Why do we need them?

The core IP protocol is a best-effort delivery service. It is unreliable and lacks built-in error reporting or management mechanisms. Support protocols are required to:

  • Map logical addresses (IP) to physical addresses (MAC) → ARP
  • Report errors (e.g., Destination Unreachable, TTL Exceeded) → ICMP
  • Debug network connectivity (Ping, Traceroute) → ICMP Applications

1. Broadcasting Implementation

(i) Limited Broadcast Address

Used to send a packet to everyone on the current network. It is never forwarded by routers.

  • IP Address: 255.255.255.255
  • MAC Address: FF:FF:FF:FF:FF:FF (48-bit)
  • Scope: Local LAN only. Router blocks it.

(ii) Direct Broadcast Address (DBA)

Used to send a packet to everyone on a specific remote network.

  • Formula: Network ID + All Host bits set to 1.
  • Example: For Network 10.0.0.0/8
    DBA = 10.255.255.255

2. ARP (Address Resolution Protocol)

ARP is used to find the MAC Address of a device when its IP Address is known.

sequenceDiagram participant Source as Sender (Host A) participant Net as Network participant Dest as Target (Host B) Note over Source: Knows IP_B, needs MAC_B Source->>Net: ARP Request (Who is IP_B?) Note right of Source: Broadcast (FF:FF:FF:FF:FF:FF) Net-->>Dest: Delivers to All Dest->>Source: ARP Reply (I am IP_B, my MAC is MAC_B) Note left of Dest: Unicast (MAC_A)

Key Characteristics

  • ARP Request: Broadcast (MAC Destination: FF:FF:FF:FF:FF:FF).
  • ARP Reply: Unicast (Source MAC to Destination MAC).
  • Encapsulation: Encapsulated directly in a DLL (Data Link Layer) Frame.
The 4 Communication Cases for ARP
  1. Host to Host (Same Network): Sender uses ARP to find Receiver's MAC.
  2. Host to Host (Different Network): Sender looks at Routing Table → Finds Next Hop (Router) IP → Uses ARP to find Router's MAC.
  3. Router to Router: Router uses ARP to find the next Router's MAC.
  4. Router to Host: Last Router uses ARP to find the Destination Host's MAC on the local LAN.
Important Terms:
ARP Cache: A table storing resolved IP-MAC pairs to avoid repeated ARP requests.
Cache Timeout: Time entries stay valid in the table (usually 20 mins).

Protocol Comparison

Protocol Mapping Direction Usage
ARP IP Address → MAC Address Standard Communication
RARP MAC Address → IP Address Diskless Workstations (Obsolete, see DHCP)
DNS Domain Name → IP Address Web Browsing
DHCP Dynamic IP Allocation Modern "Plug & Play" networking

3. ICMP (Internet Control Message Protocol)

ICMP is a network layer protocol used by routers and hosts to send error messages and operational information.

Encapsulation

ICMP messages are encapsulated inside IP Datagrams.

block-beta columns 4 block:IP["IP Header"]:2 block:ICMP["ICMP Message"]:2 end space block:Details["ICMP Header + Data"]:2

Types of ICMP Messages

1. Error Reporting

Generated when a router or host encounters a problem processing an IP packet.

2. Query Messages

Request/Reply pairs used to get specific information from a host (e.g., timestamps, status).

When is ICMP NOT generated?
  • In response to an ICMP Error Message (prevents infinite loops).
  • For fragmented datagrams (except the first fragment).
  • For Multicast addresses.
  • For Special addresses (e.g., Loopback 127.0.0.0).

4. ICMP Error Reporting Messages

The direction of these messages is always Router/Receiver → Original Sender.

1. Destination Unreachable

Sent when a packet cannot be delivered.

  • Destination Host Unreachable: Link down, ARP failed, or hardware failure.
  • Destination Port Unreachable: Packet arrived at host, but no process is listening on that port (Key for Traceroute).
  • Fragmentation Required: Packet > MTU, but the Don't Fragment (DF) flag is set to 1. Used in Path MTU Discovery.

2. Time Exceeded (TTL Exceeded)

Generated when the Time To Live (TTL) field in the IP header reaches 0.

  • Used to prevent infinite looping of packets.
  • Application: This is the core mechanism behind Traceroute.

3. Source Quench

A rudimentary form of Congestion Control.

  • If a router/host is receiving packets too fast (buffer overflow), it sends a Source Quench message to the Sender.
  • Tells the Sender to slow down the transmission rate.

4. Parameter Problem

Sent if there is a header error or ambiguity (e.g., calculated Checksum does not match received Checksum).

5. Redirection

Sent by a router to the sender if the sender is using a sub-optimal path.

  • "I am forwarding this, but next time use Router Y directly."
  • Updates the routing table on the host.

5. ICMP Query Messages

Type Description
Echo Request & Reply Used by ping to check host liveness.
Timestamp Request & Reply Used to determine Round Trip Time (RTT) and clock synchronization between two machines.
Address Mask Request & Reply A host sends this to a router to find out the Subnet Mask of the network (e.g., if it knows IP but not mask /24).
Router Solicitation & Adv. Host asks "Are there any routers?" (Solicitation). Routers reply "I am here" (Advertisement).

6. Applications of ICMP

A. Traceroute (Trace Route)

Identify the path (hops) a packet takes to reach a destination.

Mechanism:

  1. Sender sends UDP (or ICMP) packet with TTL = 1.
  2. Router 1 drops it (TTL becomes 0) and sends ICMP Time Exceeded back. Sender records R1 IP.
  3. Sender sends packet with TTL = 2. Router 2 drops it and replies.
  4. Repeat until Destination is reached.
  5. Destination sends ICMP Destination Port Unreachable (because Traceroute intentionally uses an unlikely port) to signal completion.
sequenceDiagram autonumber participant S as Source participant R1 as Router 1 participant R2 as Router 2 participant D as Destination S->>R1: Packet (TTL=1) Note right of R1: TTL=0 -> Drop R1-->>S: ICMP Time Exceeded S->>R2: Packet (TTL=2) R2->>R2: Pass R1 Note right of R2: TTL=0 -> Drop R2-->>S: ICMP Time Exceeded S->>D: Packet (TTL=3) D-->>S: ICMP Dest Port Unreachable Note over S: Path Complete: {R1, R2, D}

B. Path MTU Discovery (PMTUD)

Determines the smallest MTU (Maximum Transmission Unit) along the path to avoid fragmentation.

  • Sender sets DF (Don't Fragment) = 1.
  • If a router's MTU is smaller than packet size, it drops packet and sends ICMP Destination Unreachable (Fragmentation Needed).
  • Sender reduces packet size and tries again.

GATE Corner (Key Takeaways)

  • GATE 2019 ARP Request vs Reply:
    Request is Broadcast MAC.
    Reply is Unicast MAC.
  • GATE 2016 Protocol Mappings:
    DNS: Domain Name → IP
    ARP: IP → MAC
    DHCP: Assigns IP Config
    RARP: MAC → IP
  • GATE 2021 Statement Analysis:
    S1: Destination MAC of ARP reply is Broadcast (False).
    S2: Destination MAC of ARP request is Broadcast (True).
