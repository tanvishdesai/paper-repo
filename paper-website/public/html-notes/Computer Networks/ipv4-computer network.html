IPv4 Addressing & Subnetting

Comprehensive guide to Computer Networks addressing architecture, from Classful basics to advanced CIDR and Routing logic.

1. IP Fundamentals

Definition

IPv4 Structure

A 32-bit logical address usually represented in Dotted Decimal Notation (e.g., 192.168.1.1).

  • Total Addresses: \(2^{32} \approx 4 \text{ Billion}\)
  • Structure: Network ID (NID) + Host ID (HID)
  • Management: IANA (Internet Assigned Numbers Authority)
Communication

Types of Transmission

  • Unicast: One-to-One (Source \(\to\) Destination).
  • Broadcast: One-to-All.
    • Limited Broadcast (LBA): 255.255.255.255 (Local network only).
    • Direct Broadcast (DBA): Host bits set to 1 (Target specific network).
  • Multicast: One-to-Many (Specific Group, Class D).
Key Rule: An IP address with all 0s in the Host ID is the Network ID. An IP address with all 1s in the Host ID is the Direct Broadcast Address. Neither can be assigned to a specific host (computer).

2. Classful Addressing

The original Internet addressing architecture divided the address space into 5 classes.

Class Leading Bits Range (1st Octet) Format (N=Net, H=Host) Default Mask Networks Hosts per Network
A 0 1 - 126 N.H.H.H 255.0.0.0 (/8) \(2^7 - 2 = 126\) \(2^{24} - 2 \approx 16M\)
B 10 128 - 191 N.N.H.H 255.255.0.0 (/16) \(2^{14} \approx 16K\) \(2^{16} - 2 = 65,534\)
C 110 192 - 223 N.N.N.H 255.255.255.0 (/24) \(2^{21} \approx 2M\) \(2^8 - 2 = 254\)
Special Reserved Addresses
  • 127.x.x.x (Loopback): Used for self-connectivity testing. Packet never leaves the NIC. Cannot be a source or destination on the wire.
  • 0.0.0.0: Used as source IP during bootstrap (DHCP Request) when IP is unknown.
  • 255.255.255.255: Limited Broadcast Address (Current Network).

3. Subnetting

The practice of dividing a single large network into smaller sub-networks (subnets) to reduce broadcast traffic and improve security.

The Mechanism

We borrow bits from the Host ID part to create a Subnet ID.

block-beta columns 3 block:nid NID end block:new SID HID end nid -- "Old Structure" --> NID_Label new -- "New Structure" --> New_Label

Subnet Mask (SM): 1s represent Network+Subnet, 0s represent Host.

Formulas

  • Subnets: \(2^S\) (where S = bits borrowed)
  • Hosts per Subnet: \(2^H - 2\) (where H = remaining host bits)
  • Block Size (Magic Number): Total IPs per subnet. Calculated as \(256 - \text{Mask Value}\) (in the interesting octet).

Example Calculation (Class C)

IP: 200.200.200.0, Borrow 3 bits for subnetting.

Default Mask: 255.255.255.0  (/24)
New Mask:     255.255.255.224 (/27) -> 11100000 in last octet

Number of Subnets: 2^3 = 8
Hosts per Subnet:  2^5 - 2 = 30
Block Size:        2^5 = 32

Subnet 1: 200.200.200.0   to 200.200.200.31
Subnet 2: 200.200.200.32  to 200.200.200.63
...
AD Rule (Quick Check): If calculating ranges, start with the NID. Add the Block Size to find the next NID. The address immediately before the next NID is the Broadcast Address of the current subnet.

4. Classless Addressing (CIDR)

CIDR (Classless Inter-Domain Routing) eliminates fixed classes. Addresses are represented as A.B.C.D/n, where n is the prefix length (Network Bits).

Notation Subnet Mask Block Size
/24 255.255.255.0 256 IPs
/25 255.255.255.128 128 IPs
/26 255.255.255.192 64 IPs
/30 255.255.255.252 4 IPs (Often used for Point-to-Point)

CIDR Rules

  1. IP addresses in a block must be contiguous.
  2. Block size must be a power of 2 ($2^k$).
  3. First IP address must be divisible by the size of the block.

5. Supernetting (Aggregation)

Combining small networks into a larger one to reduce routing table size (Route Aggregation). It is the inverse of subnetting.

graph LR A[Network 1: /24] --> R[Router] B[Network 2: /24] --> R C[Network 3: /24] --> R D[Network 4: /24] --> R R -->|Advertises| E[Supernet: /22]

How to Calculate Supernet Mask

Example: Combine 4 Class C networks: 200.1.0.0, 200.1.1.0, 200.1.2.0, 200.1.3.0.

  1. Check if contiguous: Yes.
  2. Check count: 4 networks (\(2^2\)). Valid.
  3. Logic: We are merging, so we move the mask bit to the left by \(\log_2(\text{count})\).
  4. Original Mask: /24. Shift left by 2 bits (\(\log_2 4\)).
  5. Supernet Mask: /22 (255.255.252.0).
  6. Supernet ID: 200.1.0.0/22.

6. Routing Logic

When a router receives a packet, it consults its routing table to decide where to forward it.

The Golden Rule: Longest Prefix Match
If a destination IP matches multiple entries in the routing table, the router chooses the entry with the longest mask (most specific match).

Routing Decision Flowchart

graph TD Start[Packet Arrives] --> Extract[Extract Destination IP] Extract --> ApplyMask1[Apply Mask of Entry 1] ApplyMask1 --> Match1{Matches NID?} Match1 -- Yes --> Save1[Candidate 1] Match1 -- No --> Next1[Next Entry] Save1 --> ApplyMask2[Apply Mask of Entry 2] ApplyMask2 --> Match2{Matches NID?} Match2 -- Yes --> Save2[Candidate 2] Save2 --> Compare[Compare Candidates] Compare --> Select[Select Entry with HIGHEST /n] Select --> Forward[Forward Packet]

Example

Destination IP: 10.1.1.5

Entry Network Mask Match?
A 10.0.0.0 /8 ✅ Matches (10...)
B 10.1.0.0 /16 ✅ Matches (10.1...)
C 10.1.1.0 /24 ✅ Matches (10.1.1...)

Result: Router chooses Entry C (/24 is longer than /16 and /8).
